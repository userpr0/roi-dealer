# database/migrations

Версионированные миграции PostgreSQL. **Появятся в PHASE 02** вместе с выбором инструмента миграций (ADR).

Правила:

- миграции только вперёд, применённые миграции не редактируются;
- каждая миграция воспроизводима на пустой БД;
- деструктивные изменения (drop, необратимые преобразования) требуют human approval (§2.7).
