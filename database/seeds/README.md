# database/seeds

**Пока не используются** (решение PHASE 02, Feature Kill Gate §2.15): integration-тесты создают данные доменными фабриками в отдельной временной БД, а локальной разработке достаточно пустой схемы.

Если seeds понадобятся, они будут содержать только синтетические данные: никаких реальных клиентов, персональных данных или секретов.
