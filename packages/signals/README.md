# @roi-dealer/signals

**Статус:** реализован (PHASE 06 — Signals & Pain, [спецификация](../../docs/phases/06_signals_pain.md)).

## Назначение

Агент `pain-analyst` находит боли в Evidence:

1. AI-задача `extract-signal` решает, есть ли в цитате боль, и записывает её одним утверждением.
2. Код проверяет, что цитата действительно есть в тексте, и создаёт `Signal`.
3. Похожие боли ищутся сначала по словам (бесплатно), затем AI-задача `match-pain` сравнивает ближайшие.
4. Сигнал начинает нового кандидата `Pain` или дополняет найденного.

## Правила

- **Доступ:** агент работает только через свою личность. Доступ выдаёт владелец в `/decisions` (PHASE 04).
- **Разбор:** каждое Evidence разбирается один раз — журнал `signal_extractions`.
- **AI вызывается только через `runTask`**, в пределах долей дня: `extract-signal` — 15 %, `match-pain` — 5 %.
- **Стоп-кран** проверяется первым шагом.
- **AI только предлагает.** Цитаты проверяет, а сигналы и боли создаёт и меняет код через функции `@roi-dealer/domain`.
- **Тексты постов** не попадают в логи.
