# @roi-dealer/judges

**Статус:** реализован (PHASE 11 — Judges, [спецификация](../../docs/phases/11_judges.md)).

## Назначение

- **`judgeOpportunityTask`** — одна оценка одного критерия: балл 1–5, обоснование, ссылки на цитаты, опасения. Шесть критериев: рынок, боль и ценность, экономика, сборка, риск, повторное использование.
- **`toJudgement`** — проверка ответа кодом.
- **`judgesAgent`** — агент судей на общем запуске `@roi-dealer/agents`: шесть отдельных вызовов на версию черновика, затем `submitOpportunityForReview`.
- **Итог 0–100 и слабые места** — `judgePanel` в `@roi-dealer/domain`.

## Правила

- **Судьи оценивают; решает владелец** (PHASE 12).
- **Выводы — со ссылками на Evidence** (§2.5): без них рынок, боль и экономика — не выше 2.
- **Числа итога считает код** (§2.13).
- **AI — только через `runTask`,** уровень `strong`; порядок моделей задают evals.
