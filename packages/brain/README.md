# @roi-dealer/brain

**Статус:** реализован (PHASE 08 — Company Brain v0.1, [спецификация](../../docs/phases/08_company_brain.md)).

## Назначение

- **`searchBrain`** — полнотекстовый поиск по болям, возможностям, доказательствам, знаниям и решениям. Если записей со всеми словами нет, показываются похожие.
- **`planQuestion` / `answerQuestion`** — вопрос владельца распознаётся правилами. Ответ — числа и записи из БД с источником (§7.3), без AI.
- **`ownerNote`** — заметка владельца как `KnowledgeAsset`.
- **`similarCases`** — похожие прошлые случаи для судей и карточки решения.

## Правила

- **Только готовые параметризованные запросы** `database.brain`. Текст пользователя никогда не попадает в SQL.
- **Цифры считает запрос к БД**, не модель (§2.13).
- **Отчёты evals** в поиск не попадают.
