# @roi-dealer/crm

**Статус:** реализован (PHASE 20 — CRM / Outcomes, минимум, [спецификация](../../docs/phases/20_crm_outcomes.md)).

Заявки со страниц тестов. Сущность `Lead` — в `@roi-dealer/domain` (без персональных данных); почта — в `database.leadContacts` (таблица `lead_contacts`, без истории, удаляется физически); форма и страницы — в `@roi-dealer/site`; `/leads` и `/forget` — в `@roi-dealer/command-center`.

## Что делает

| Функция                                       | Что делает                                                                                                        |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `parseLeadForm`                               | Разбор формы: почта (нижний регистр, до 254 символов), согласие `consent=yes`, поле-ловушка `website` для роботов |
| `captureLead`                                 | Одной транзакцией: заявка, почта, шаг воронки `lead`; повтор той же почты в тесте — без новой заявки              |
| `eraseContacts`, `forgetEmail`                | Удаление почты (по заявке или по адресу во всех тестах) и пометка заявок `contactErasedAt`                        |
| `purgeExpiredContacts`, `createLeadRetention` | Срок хранения: почта не-клиентов через 180 дней после теста; стоп-кран — первым шагом                             |

## Правила использования

- Почту пишет только интеграция «Сайт тестов» (`lead.capture`), читает и удаляет — владелец и срок хранения (`lead.manage`).
- Почта не попадает в события, логи и уведомления; в боте — только в `/leads` и в вопросе `/forget`.
- Статусы и итог клиента меняет только владелец (домен).
