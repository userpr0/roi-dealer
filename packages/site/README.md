# @roi-dealer/site

**Статус:** реализован (PHASE 19a — предпросмотр лендинга, [спецификация](../../docs/phases/19a_media_factory.md)).

Страницы, которые отдаёт `apps/api`: обработчики возвращают статус и HTML, а `api` сопоставляет их с маршрутами и добавляет заголовки безопасности (`PAGE_SECURITY_HEADERS`: строгий CSP, `DENY`, `no-store`).

| Маршрут `api`    | Обработчик    | Что отдаёт                                                                                       |
| ---------------- | ------------- | ------------------------------------------------------------------------------------------------ |
| `GET /p/<token>` | `previewPage` | Закрытый предпросмотр черновика или одобренного лендинга; неизвестный, отклонённый, снятый — 404 |

## Правила использования

- Только чтение через `@roi-dealer/database`; страницы собирает `renderLanding` из `@roi-dealer/media`.
- Без JavaScript и внешних ресурсов; тексты не логируются.

## Export surface

| Экспорт                    | Назначение                       |
| -------------------------- | -------------------------------- |
| `previewPage`              | Предпросмотр по токену           |
| `noticePage`, `NOT_FOUND`  | Служебная страница и ответ 404   |
| `SitePage`, `PACKAGE_NAME` | Тип ответа; идентификатор пакета |
