# @roi-dealer/site

**Статус:** реализован (PHASE 19a — предпросмотр лендинга, [спецификация](../../docs/phases/19a_media_factory.md); PHASE 21 — выпущенные лендинги и счётчик воронки, [спецификация](../../docs/phases/21_solution_factory.md); PHASE 20 — форма заявки и `/privacy`, [спецификация](../../docs/phases/20_crm_outcomes.md)).

Страницы, которые отдаёт `apps/api`: обработчики возвращают статус и HTML или адрес перехода, а `api` сопоставляет их с маршрутами и добавляет заголовки безопасности (`PAGE_SECURITY_HEADERS`: строгий CSP, `DENY`, `no-store`).

| Маршрут `api`               | Обработчик               | Что отдаёт                                                                                                         |
| --------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `GET /p/<token>`            | `previewPage`            | Закрытый предпросмотр черновика или одобренного лендинга; неизвестный, отклонённый, снятый — 404                   |
| `GET /l/<slug>`             | `landingPage` (`page`)   | Выпущенный лендинг, пока запуск одобрен или тест идёт; после теста — 410, не выпущен — 404; просмотр → `attention` |
| `GET /l/<slug>/go`          | `landingPage` (`go`)     | Нажатие кнопки → `cta_click` → 303 на форму `/l/<slug>/join` (без `PUBLIC_CONTACT_EMAIL` — на `/thanks`)           |
| `GET`/`POST /l/<slug>/join` | `landingPage` (`join`)   | Форма: почта, согласие, ловушка; отправка → `captureLead` (`@roi-dealer/crm`) → 303 на `/joined`                   |
| `GET /l/<slug>/joined`      | `landingPage` (`joined`) | «Вы в списке» и адрес для удаления                                                                                 |
| `GET /l/<slug>/thanks`      | `landingPage` (`thanks`) | Честная страница «продукт ещё не готов, ничего не собрано»                                                         |
| `GET /privacy`              | `privacyPage`            | Что собирается, срок хранения, адрес для запросов (`PUBLIC_CONTACT_EMAIL`)                                         |

## Счётчик воронки (`createSiteTracker`)

- Пишет как интеграция «Сайт тестов» (`SITE_TRACKER`, `integration:site`) с правом `funnel.track`; доступ запрашивает `api` (`SITE_ACCESS`), выдаёт владелец.
- Считает только пока тест идёт: стоп-кран → активный доступ → повтор того же посетителя за 30 минут (солёный хеш в памяти) → роботы, превью, предзагрузка, `HEAD` → не больше 600 событий в минуту.
- Адрес и браузер посетителя не хранятся и не логируются; в событие воронки попадают только UTM-метки.

## Правила использования

- Страницы только читают через `@roi-dealer/database`; пишет только счётчик — события воронки. Страницы собирает `renderLanding` из `@roi-dealer/media`.
- Без JavaScript, cookies и внешних ресурсов; тексты не логируются.
