# @roi-dealer/command-center

**Статус:** реализован (13b — ранний шаг PHASE 13, D-002, D-009, D-010, [спецификация](../../docs/phases/13b_owner_approvals.md); доступы — PHASE 04, [спецификация](../../docs/phases/04_identity_access.md); боли, возможности и Company Brain — PHASE 06–08; агенты и рыночный контекст в `/opportunities` — PHASE 10; оценки судей там же — PHASE 11).

Логика пульта владельца в Telegram. `apps/bot` только связывает её с Telegram (`@roi-dealer/telegram`) и PostgreSQL (`@roi-dealer/database`).

## Что делает

| Команда / кнопка                                       | Поведение                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/decisions`                                           | Карточки ожидающих ApprovalRequest с неистёкшим сроком (ближайший — первым, до 10), кнопки `ap:a:<id>` / `ap:r:<id>`                                                                                                                                                                                                                                                              |
| `op:a` / `op:r` / `op:m` → `op:ya` / `op:yr` / `op:ym` | Карточка возможности на решение (PHASE 12): вопрос, затем `createDecision` от `owner` и `applyOpportunityDecision` одной командой с ключом `tg-callback-<id>`; в кнопке — версия возможности, устаревшая карточка ничего не меняет; `op:c` — назад. Карточки приходят и сами: раз в 5 минут, каждая версия один раз (`decision-card-<id>-v<n>`), стоп-кран останавливает рассылку |
| `ap:a` / `ap:r` → `ap:ya` / `ap:yr`                    | Вопрос с суммой, затем решение: `database.command` с ключом `tg-callback-<id>` и `correlation_id` `tg-update-<id>`; решает домен (`resolveApprovalRequest`, актор `owner`); `ap:c` — назад к карточке                                                                                                                                                                             |
| `/stop [причина]`, `/resume`                           | Подтверждение (`ks:y:<nonce>` / `ks:n:<nonce>`, 10 минут, хранится в памяти), затем `pauseSystem` / `resumeSystem` командой с ключом                                                                                                                                                                                                                                              |
| `/journal`, `/history`                                 | Кнопки `jr:` / `hs:` `day` / `week` / `month`: события периода из `events.list`, время по Киеву, до 30 последних строк; история — только решения, одобрения, расходы, вехи экспериментов, стоп-кран                                                                                                                                                                               |
| `/digest`, 10:00 `Europe/Kyiv`                         | Ожидающие решения и ближайший срок, изменения за сутки (из них — владельца), расходы за сутки, стоп-кран. По расписанию — один раз в день: команда с ключом `digest-<дата>`; пропущенный — до 12:00                                                                                                                                                                               |
| `/access`, `pa:`                                       | Личности агентов, интеграций и участников: ⏸ приостановить / ▶️ вернуть / ⛔ отозвать — после подтверждения, командой с ключом; число отклонённых попыток за 7 дней                                                                                                                                                                                                               |
| `access_grant` в `/decisions`                          | Одобрение запроса доступа делает личность активной, отклонение — отзывает её, в той же команде                                                                                                                                                                                                                                                                                    |
| `/pains`, `/opportunities`                             | Боли (PHASE 06) и черновики возможностей с оценкой (PHASE 07); право `research.read`                                                                                                                                                                                                                                                                                              |
| `/search <слова>`                                      | Поиск `@roi-dealer/brain`: до 10 записей — вид, заголовок, фрагмент, дата; нет точных — похожие; кириллица — подсказка (PHASE 08)                                                                                                                                                                                                                                                 |
| `/ask <вопрос>`                                        | Ответ правилами из БД с источником: расходы, AI, количества, новое; иначе — поиск (PHASE 08)                                                                                                                                                                                                                                                                                      |
| `/note <текст>`, `nt:`                                 | Подтверждение (`nt:y:<nonce>` / `nt:n:<nonce>`, 10 минут, в памяти), затем `KnowledgeAsset` с тегом `owner-note` командой с ключом; право `research.write` (PHASE 08)                                                                                                                                                                                                             |
| `/agents`                                              | Каждый агент: доступ, последний запуск, сутки (запуски, обработано, сбои) и стоимость AI по его актору; право `status.read` (PHASE 10)                                                                                                                                                                                                                                            |
| `/hypotheses`                                          | Гипотезы одобренных возможностей (PHASE 14); уведомление «гипотезы готовы» — один раз на возможность (`hypotheses-ready-<id>`), рассылкой карточек; право `research.read`                                                                                                                                                                                                         |

**Журнал доступа:** каждая команда и кнопка проверяет право владельца (`@roi-dealer/policies`) и записывается в `access_log`; отказы посторонним — не чаще раза в 10 минут на отправителя (`refused`). Запрос доступа для новой интеграции или агента — `requestAccess`; `ensureAccessRequest` (PHASE 05) запрашивает доступ один раз на актора и повторяет запрос, если прежний истёк без ответа.

**Evidence (PHASE 05):** в дайджесте — строка «📚 Новых доказательств за сутки: N»; в журнале подряд идущие события одного запроса (например, загрузка источника) сворачиваются в одну строку «×N».

Без базы данных (`createCommandCenter({ database: undefined })`) те же команды отвечают, что база не подключена.

## Правила

- Состояние меняет только домен; каждое изменение — идемпотентная команда БД с событием от `owner`.
- Каждая будущая автоматизация и автоматическая трата первым шагом вызывает `assertAutomationRunning` (правило в `CLAUDE.md`).
- Сообщения отправляются без parse mode: названия, написанные агентами, не могут внедрить разметку. Тексты сообщений не логируются.
