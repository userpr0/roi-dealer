# @roi-dealer/evidence

**Статус:** реализован (PHASE 05, [спецификация](../../docs/phases/05_evidence_engine.md)).

Evidence Engine: законный сбор рыночных данных с происхождением и без персональных данных (§2.5, §2.20, §2.21, D-014 п.5–6).

## Состав

| Экспорт                                                    | Назначение                                                                                                                                                                       |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SOURCE_CATALOG`, `catalogEntrySchema`, `connectableEntry` | Каталог источников: доступ, условия, стоимость, лимиты, поля, риск ПД, рынки, вердикт и дата проверки. Только `allowed` можно подключать (`not_cataloged` / `not_allowed`)       |
| `accessRequestFor`, `integrationActor`, `sourceFor`        | Запрос доступа владельцу (условия в тексте карточки), актор `integration:source:<ключ>`, запись `Source`                                                                         |
| `redactPersonalData`                                       | Замена email, телефонов, ссылок на профили, `@ников`, SSN, карт (Луна), IPv4 до записи                                                                                           |
| `htmlToText`                                               | Текст из HTML постов (абзацы, ссылки, сущности)                                                                                                                                  |
| `SourceConnector`, `createHackerNewsConnector`             | Коннектор: Ask HN через официальный API, только новые id, не больше лимита, таймаут, SHA-256 ответов; автор не читается                                                          |
| `createLemmyConnector`                                     | Коннектор Lemmy (05b): новые посты трёх сообществ lemmy.world через официальный API; только посты, созданные на lemmy.world, английские, без удалённых и NSFW; автор не читается |
| `ensureConnection`                                         | Источник по каталогу + запрос доступа в `/decisions` (`ensureAccessRequest` из `@roi-dealer/command-center`); отказ владельца → источник `retired`                               |
| `collectEvidence`                                          | Стоп-кран → каталог → источник → доступ → загрузка → очистка → одна транзакция `SourceSnapshot` + Evidence                                                                       |
| `createEvidenceScheduler`                                  | Расписание в `apps/worker`: без наложения запусков, интервал каталога считается только для реальных запросов                                                                     |

## Добавить источник

1. Проверить условия использования. Записать в `SOURCE_CATALOG` вердикт и дату проверки — до кода.
2. Если `allowed`, написать коннектор (`SourceConnector`). Тесты — с локальным фейковым сервером (`tests/support/fake-*.ts`).
3. Подключить коннектор в `apps/worker/src/main.ts`. Доступ интеграции владелец выдаёт в `/decisions`.
