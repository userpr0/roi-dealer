# @roi-dealer/rewards

**Статус:** реализован (PHASE 17 — Reward Engine, [спецификация](../../docs/phases/17_rewards.md)).

Правила вознаграждений и проверки перед начислением. Цепочка §2.10: Contributor → Contribution → Result → Verification → Reward Calculation → Approval → Payable → Paid. Сущности и переходы — в `@roi-dealer/domain` (`Contribution`, `Reward`, `recordRewardPayout`); пульт — в `@roi-dealer/command-center` (`/contribution`, `/rewards`, `/reward`, `/paid`).

## Правила

| Правило            | Условие владельца | Сумма                                                                                 |
| ------------------ | ----------------- | ------------------------------------------------------------------------------------- |
| `fixed-v1`         | сумма в USD       | ровно она, от $0.01 до $10 000                                                        |
| `revenue-share-v1` | доля 0–50 %       | доля подтверждённых оплат теста за вычетом возвратов (без предзаказов), вниз до цента |

## Проверки (`planReward`)

- вклады есть и все подтверждены (`verified`);
- все — одного участника команды (`member`): владельцу и AI-агентам вознаграждение не начисляется;
- ни один вклад не входит в другое неотменённое начисление;
- для доли — все вклады одного теста, у теста есть выручка.

Отказ называет причину и вклад. Те же правила база проверяет триггером (миграция `0014`).

## Правила использования

- Сумму считает код, условия задаёт владелец. AI в расчёте не участвует (§2.13).
- Каждая выплата — запрос `payout` в `/decisions` (D-006); деньги переводит владелец, система только записывает выплату расходом `human`.
- Пакет ничего не пишет и не платит: он чистая логика над данными, которые загрузил вызывающий.
