# Инструкции на аварии (runbooks)

> Этап A6 (D-014 п.4). Что делать, если что-то сломалось: по шагам, куда нажимать и как проверить результат.
> Обновляются, когда меняется инфраструктура: новый сервис, провайдер или ключ добавляет строку в таблицу ниже.

## Какую инструкцию открыть

| Что случилось                                                                   | Инструкция                                        | Сколько времени |
| ------------------------------------------------------------------------------- | ------------------------------------------------- | --------------- |
| Токен бота или ключ попал в чат, скриншот, репозиторий или к постороннему       | [Утечка токена или ключа](secret-leak.md)         | 5–10 минут      |
| GitHub прислал письмо о найденном секрете (secret scanning)                     | [Утечка токена или ключа](secret-leak.md)         | 5–10 минут      |
| Бот не отвечает, пришло «🔴 ROI Dealer bot остановлен», Mini App не открывается | [Сервис не работает](service-down.md)             | 5–15 минут      |
| Письмо Railway о приближении к лимиту, неожиданный счёт                         | [Резкий рост расходов](spend-spike.md)            | 5–10 минут      |
| Подозрение, что кто-то зашёл в ваш GitHub, Railway или Telegram                 | [Утечка токена или ключа](secret-leak.md#аккаунт) | 15 минут        |

## Общие правила

1. **Сначала остановить ущерб, потом разбираться.** Отозвать ключ, остановить сервис, поставить на паузу — это всегда можно откатить. Потерянные деньги и утёкшие данные — нет.
2. **Не присылайте секреты в чат**, в том числе Claude. Для разбора достаточно текста ошибки из логов: бот не пишет токен в логи.
3. **Один шаг — одна проверка.** После каждого действия смотрите, что изменилось (статус в Railway, сообщение в Telegram).
4. **После аварии** напишите Claude в свободной форме: что случилось, когда, что сделали. Claude проверит последствия и предложит, как не допустить повтора.

## Где что находится

| Система      | Что там                               | Адрес                                                                                              |
| ------------ | ------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Railway      | Бот-пульт (сервис `@roi-dealer/bot`)  | [railway.com/dashboard](https://railway.com/dashboard)                                             |
| GitHub       | Код, проверки CI, публикация Mini App | [github.com/userpr0/roi-dealer](https://github.com/userpr0/roi-dealer)                             |
| GitHub Pages | Mini App (пульт)                      | [userpr0.github.io/roi-dealer](https://userpr0.github.io/roi-dealer/)                              |
| @BotFather   | Токен бота: выпуск, отзыв             | Telegram → [@BotFather](https://t.me/BotFather)                                                    |
| Статусы      | Не сломался ли сам провайдер          | [status.railway.com](https://status.railway.com), [githubstatus.com](https://www.githubstatus.com) |

## Секреты и где они хранятся

| Секрет                | Где хранится                                                   | Как отозвать                                                 |
| --------------------- | -------------------------------------------------------------- | ------------------------------------------------------------ |
| `TELEGRAM_BOT_TOKEN`  | Railway → сервис бота → **Variables**; менеджер паролей (PROD) | @BotFather → `/revoke`                                       |
| Токен тестового бота  | Локальный `.env` на ПК; менеджер паролей (TEST)                | @BotFather → `/revoke` → тестовый бот                        |
| Recovery codes GitHub | Менеджер паролей                                               | GitHub → Settings → Password and authentication → Regenerate |

Ключи AI-провайдера (PHASE 09), платёжного провайдера и рекламных кабинетов добавятся в эту таблицу при подключении.
