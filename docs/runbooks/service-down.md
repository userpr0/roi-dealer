# Сервис не работает

## Бот не отвечает

**Признаки:** `/status` без ответа больше минуты; пришло «🔴 ROI Dealer bot остановлен», хотя вы ничего не обновляли; карточка в Railway красная.

### 1. Посмотреть статус (1 минута)

[railway.com/dashboard](https://railway.com/dashboard) → проект → карточка **@roi-dealer/bot**:

| Статус на карточке           | Что это значит                                         | Что делать                             |
| ---------------------------- | ------------------------------------------------------ | -------------------------------------- |
| **Online**                   | Контейнер работает, но бот может не получать сообщения | Шаг 2 (логи)                           |
| **Building** / **Deploying** | Идёт обновление после слияния в `main`                 | Подождите 2–4 минуты                   |
| **Crashed**                  | Бот упал и Railway не смог его поднять                 | Шаг 2 (логи)                           |
| **Failed**                   | Не собралась или не запустилась новая версия           | Шаг 2, затем шаг 3 (откат)             |
| Карточки нет или всё серое   | Сервис удалён или остановлен из-за лимита расходов     | [Резкий рост расходов](spend-spike.md) |

Заодно откройте [status.railway.com](https://status.railway.com): если у Railway авария, остаётся ждать.

### 2. Логи (2 минуты)

Карточка → **Deployments** → верхняя строка → **View logs**. Найдите последние строки с `"level":"error"` или `"level":"fatal"` и сверьте с таблицей:

| В логах                                            | Причина                                            | Что делать                                                                                       |
| -------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `Invalid configuration: TELEGRAM_BOT_TOKEN …`      | Переменная пустая или испорчена                    | **Variables** → проверьте три переменные → **Deploy**                                            |
| `bot failed to start` … `(401)`                    | Токен отозван или неверный                         | Новый токен в @BotFather → [инструкция](secret-leak.md#2-вписать-новый-токен-в-railway-2-минуты) |
| `telegram polling conflict: another bot instance…` | Этот же бот запущен где-то ещё (ПК, второй сервис) | Остановите лишний экземпляр; на ПК используйте тестового бота                                    |
| ``The executable `pnpm` could not be found``       | Заполнено поле Custom Start Command                | **Settings** → **Deploy** → очистите поле → **Deploy**                                           |
| `sender is not the owner` с вашим `user_id`        | В `TELEGRAM_OWNER_USER_ID` не ваш Id               | Впишите `user_id` из лога в **Variables** → **Deploy**                                           |
| Ошибок нет, но сообщения не доходят                | Сбой у Telegram или сети                           | Шаг 3 (перезапуск); если не помогло — подождите 15 минут                                         |

Если строки нет в таблице — пришлите Claude последние 20 строк лога (токена в логах нет).

### 3. Перезапуск или откат (2 минуты)

- **Перезапуск** той же версии: **Deployments** → верхняя строка → **⋮** → **Restart**.
- **Откат** на прошлую рабочую версию, если сломала новая: **Deployments** → **History** → последняя строка со статусом **Success** или **Removed** до поломки → **⋮** → **Rollback** (или **Redeploy**). Затем попросите Claude найти и исправить причину в коде: откат — временная мера, следующее слияние в `main` снова выкатит новую версию.

### 4. Проверить

- [ ] Карточка **Online**.
- [ ] В Telegram пришло «🟢 ROI Dealer bot запущен».
- [ ] `/status` отвечает.

## Mini App (кнопка «Пульт») не открывается

1. Откройте [userpr0.github.io/roi-dealer](https://userpr0.github.io/roi-dealer/) в браузере.
   - Открывается → проблема в Telegram: закройте и снова откройте чат с ботом.
   - Ошибка 404 → шаг 2.
2. GitHub → репозиторий → **Actions** → слева **Deploy miniapp** → последний запуск.
   - Красный → откройте его, **Re-run all jobs**. Если снова красный — пришлите Claude название упавшего шага.
   - Зелёный, но сайт не открывается → проверьте [githubstatus.com](https://www.githubstatus.com) (раздел Pages) и подождите 10 минут.
3. **Settings** → **Pages**: источник — **GitHub Actions**. **Settings** → **Environments** → **github-pages**: разрешена ветка `main`.

Это не авария: `main` защищена, и непроверенный код не попадёт ни в бота, ни в Mini App. Если красный PR открыл Claude, он исправляет его сам. Если красный запуск на `main` — напишите Claude.
