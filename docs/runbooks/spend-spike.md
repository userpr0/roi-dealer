# Резкий рост расходов

**Признаки:** письмо Railway об оповещении ($15) или жёстком лимите ($20); сервисы остановились без вашей команды; в **Usage** сумма растёт быстрее обычного. Позже добавятся письма AI-провайдера (PHASE 09) и рекламных кабинетов (PHASE 15) и автопауза в пульте (D-014 п.10).

> Лимиты на старт (D-007): инфраструктура — $20 в месяц, AI — $50 в месяц с PHASE 09. Жёсткий лимит в Railway останавливает все сервисы при $20, поэтому больше этой суммы Railway не спишет.

## Railway

### 1. Понять, что тратит (2 минуты)

1. [railway.com](https://railway.com) → аватар или workspace → **Usage**.
2. Посмотрите расходы **по сервисам** и **по ресурсам** (CPU, Memory, Network, Volume).

| Что видно                                                            | Вероятная причина                                                 |
| -------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Сервисы, которых не должно быть (`api`, `worker`, `miniapp` и т. п.) | Railway сам создал сервис из репозитория                          |
| Бот ест много памяти или CPU                                         | Ошибка в коде (утечка памяти, бесконечный цикл)                   |
| Большой **Network** (исходящий трафик)                               | Кто-то использует сервис; у бота не должно быть публичного адреса |
| Больше одной реплики                                                 | Изменены настройки **Scale**                                      |

### 2. Остановить лишнее (2 минуты)

- **Лишний сервис:** карточка → **Settings** → внизу **Delete Service**.
- **Бот тратит слишком много:** карточка → **Deployments** → верхняя строка → **⋮** → **Remove**. Бот остановится, в Telegram придёт «🔴 ROI Dealer bot остановлен» (если он ещё в состоянии его отправить). Запустить снова: **⋮** → **Redeploy**.
- **Публичный адрес у бота:** **Settings** → **Networking** → удалите домен.

### 3. Проверить настройки защиты (2 минуты)

- [ ] **Usage** → **Usage limits**: оповещение $15, жёсткий лимит $20.
- [ ] Бот → **Settings** → **Scale**: 1 реплика, лимиты 1 vCPU и 0.5 GB.
- [ ] Бот → **Settings** → **Deploy** → **Serverless** выключен, **Networking** без публичного домена.
- [ ] В проекте только нужные сервисы (сейчас — один бот).

### 4. После

Напишите Claude: сколько потрачено, какой сервис, какой ресурс. Если причина в коде, Claude найдёт её и исправит через pull request.

## Сработал жёсткий лимит ($20)

Railway остановил все сервисы до начала следующего расчётного месяца или до повышения лимита. Бот не работает.

1. Выполните шаги 1–3 выше и уберите причину.
2. Решите, поднимать ли лимит: **Usage limits** → **Hard limit**. Повышение бюджета на инфраструктуру выше $20 — ваше решение (D-006, D-007). Сообщите Claude новое значение, чтобы он обновил `docs/OWNER_DECISIONS.md`.
3. Запустите бота: **Deployments** → **⋮** → **Redeploy**, дождитесь «🟢 запущен».

## Другие провайдеры

Когда появятся AI-провайдер, платёжный провайдер и рекламные кабинеты, для каждого сюда добавится раздел: где смотреть расходы, как поставить на паузу, где лимит. Общий порядок тот же: **остановить трату → найти причину → проверить лимиты → написать Claude**.
