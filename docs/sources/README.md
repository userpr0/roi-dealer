# Источники данных: отчёты разведчика

Разведчик источников (D-026) ищет новые данные, которые можно использовать законно: официальные API, открытые данные и доступ по регистрации. Каждый источник он проверяет по официальному тексту условий. Как он работает — [`.claude/skills/source-scout/SKILL.md`](../../.claude/skills/source-scout/SKILL.md).

- **Вердикты** — в каталоге `SOURCE_CATALOG` (`packages/evidence/src/catalog.ts`). Это архив: каждый проверенный источник остаётся в нём с любым вердиктом, поэтому разведчик не проверяет его второй раз. В боте каталог показывает `/sources`.
- **Отчёты** — файлы `scout-ГГГГ-ММ-ДД.md` в этой папке: что проверено, что подключено, что нужно от владельца и какие сайты ещё закрыты для среды разработки.
- **Расписание** — раз в неделю, по понедельникам. Можно запустить и вручную: «Запусти разведчика источников».

Решения о доступе остаются за владельцем: каждый новый источник просит доступ в `/decisions`.
