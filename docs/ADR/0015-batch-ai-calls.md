# ADR-0015: Пакетный режим AI для несрочных задач (поправка к ADR-0006)

- **Status:** Proposed
- **Date:** 2026-11-04
- **Approved by:** —

## Context

- Фаза 09c одобрена владельцем («да 09c», D-036): несрочные задачи AI — дешевле через пакетный режим провайдеров.
- Все три провайдера дают пакетный режим примерно на 50 % дешевле обычного вызова, ответ — в течение 24 часов: Anthropic Message Batches, OpenAI Batch API, Gemini Batch Mode.
- Сейчас каждый вызов синхронный: `runTask` ждёт ответа, агент сразу применяет его через домен. Пакетный режим ломает это: ответ приходит через часы. Поэтому нужна смена устройства рантайма — по правилу CLAUDE.md это ADR.
- **Экономика честно:**
  - массовые задачи сначала идут на бесплатную квоту Gemini ($0, D-025) — там пакет ничего не экономит;
  - экономия есть только на платных вызовах. Лимит AI — $50 в месяц (D-007), поэтому пакет сэкономит не больше половины платной части массовых задач, то есть единицы долларов в месяц;
  - кэш запросов почти ничего не даст: наши инструкции короче порога, с которого провайдеры кэшируют (около 1 000 токенов).

## Decision (предложение)

1. **Сначала измерить, потом строить (§2.15).**
   - В `/roi` появляется строка: «Платные массовые вызовы AI за месяц: $X; пакетный режим сэкономит ≈ $X/2».
   - Порог: **$10 в месяц** платных массовых вызовов. Когда месяц его превысит, бот предложит включить пакетный режим. Решает владелец.
2. **Устройство, когда порог пройден:**
   - пакет — только для задач с пометкой `batchable` (разбор доказательств `extract-signal`, `redact-names`, `match-pain`), без личных данных в бесплатной квоте, как сейчас;
   - журнал `ai_batches`: задача, модель, число запросов, статус, стоимость; каждый ответ проходит ту же Zod-схему и тот же код применения, что и синхронный вызов;
   - worker отправляет накопленные запросы раз в несколько часов и забирает готовые ответы; стоп-кран и дневные лимиты D-021 проверяются при отправке, резервируется худшая стоимость пакета;
   - срочные задачи (судьи, карточки, лендинги) остаются синхронными.
3. **Только официальные SDK** провайдеров (ADR-0006); новых сервисов нет.

## Alternatives

| Вариант                               | Почему не выбран                                                             |
| ------------------------------------- | ---------------------------------------------------------------------------- |
| Строить пакетный режим сразу          | Экономия — единицы долларов, пока бесплатная квота покрывает массовые задачи |
| Кэш запросов вместо пакета            | Наши инструкции короче порога кэша провайдеров — экономии почти нет          |
| Перевести всё на самую дешёвую модель | Ломает правило «место модели решают эталоны» (D-021, ADR-0014)               |

## Consequences

- Сейчас: одна строка в `/roi` и порог; кода пакетов нет.
- После порога: миграция `ai_batches`, адаптеры пакетов трёх провайдеров, фейки в тестах, задержка разбора доказательств до нескольких часов.

## Rollback

Строку и порог — убрать. Пакеты (если построены) — выключить флагом: задачи вернутся к синхронным вызовам.
