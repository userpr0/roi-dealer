### Ориентир по объёму

Одна фаза ≈ одна рабочая сессия, как PHASE 00 или 01. Этап B — около 3 сессий, до Уровня 2 — около 15, до Уровня 3 — около 20. Это ориентир, а не обещание: объём уточняется в спецификации каждой фазы.

## 5. Главные риски и как они закрыты

| Риск                                       | Защита                                                                                        |
| ------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Разрастание объёма, «идеальный продукт»    | Feature Kill Gate, минимальные фазы, один рынок на старте                                     |
| Неконтролируемые расходы на AI и рекламу   | Порог $20, лимиты D-007, stop-loss, стоп-кран                                                 |
| AI принимает решения сам                   | В домене решения закреплены за владельцем; AI только предлагает                               |
| Утечка токенов и ключей                    | Секреты только в переменных хостинга; редактирование в логах; ничего секретного в репозитории |
| Выдуманные AI факты                        | Evidence first; ответы о цифрах только из БД (§2.13, §7.3)                                    |
| Нарушение правил площадок при сборе данных | Только официальные API и разрешённые коннекторы (§2.21)                                       |
| Копирование чужих материалов               | Проверка прав и извлечение паттерна вместо копии (§2.20)                                      |
