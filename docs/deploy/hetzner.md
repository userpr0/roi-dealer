# ROI Dealer на Hetzner — запуск за 15 минут

> Решение — [ADR-0010](../ADR/0010-hosting-hetzner.md), D-027. Всё, кроме этих шагов, делает сервер сам: ставит Docker, создаёт базу, получает HTTPS-сертификат, раз в 5 минут ставит новую версию после зелёного CI, каждую ночь делает копию базы.
>
> **Стоимость:** около €5–6 в месяц вместе с копиями (лимит D-007 — $20). Счёт Hetzner вносите в бот: `/cost 6 инфраструктура Hetzner`.

## 1. Подготовьте значения (5 минут)

Откройте заметку на телефоне и соберите в неё строки. Никому их не отправляйте, в том числе в чат с Claude.

| Строка                   | Где взять                                                                                                                                                                                                                                                                                                                    |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TELEGRAM_BOT_TOKEN`     | Сначала в своём боте отправьте `/stop Переезд на Hetzner` → **Да**: старая автоматика в Railway остановится и перестанет тратить AI. Потом **@BotFather** → `/mybots` → ваш бот → **API Token** → **Revoke current token** → скопируйте новый токен. Старый перестанет работать — два сервера не будут спорить за сообщения. |
| `TELEGRAM_OWNER_USER_ID` | **@userinfobot** → `/start` → число после **Id**                                                                                                                                                                                                                                                                             |
| `PUBLIC_CONTACT_EMAIL`   | Ваша почта для запросов об удалении данных (видна на странице `/privacy`)                                                                                                                                                                                                                                                    |
| `GEMINIFREE_API_KEY`     | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) → ключ проекта **без** оплаты → копировать                                                                                                                                                                                                                  |
| `GEMINI_API_KEY`         | Там же → ключ проекта **с** оплатой → копировать                                                                                                                                                                                                                                                                             |

`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `LEMONSQUEEZY_WEBHOOK_SECRET` оставьте пустыми, если этих ключей нет.

## 2. Создайте сервер (5 минут)

1. [console.hetzner.com](https://console.hetzner.com) → **New project** → имя `roi-dealer` → откройте проект.
2. **Add server** (или **Create resource** → **Servers**).
3. Заполните:

   | Поле             | Что выбрать                                                                                    |
   | ---------------- | ---------------------------------------------------------------------------------------------- |
   | Location         | Nuremberg, Falkenstein или Helsinki                                                            |
   | Image            | **Ubuntu 24.04**                                                                               |
   | Type             | **Shared vCPU → x86 (Intel/AMD)**, самый дешёвый с **4 GB** памяти (CX22 или CX23). **Не Arm** |
   | Networking       | Public IPv4 — включено, IPv6 — включено                                                        |
   | SSH keys         | пропустить                                                                                     |
   | Volumes          | пропустить                                                                                     |
   | Firewalls        | пропустить — файрвол настроит сервер                                                           |
   | **Backups**      | **включить** (+20% к цене, копия диска каждый день)                                            |
   | **Cloud config** | вставить текст ниже со своими значениями                                                       |
   | Name             | `roi-dealer`                                                                                   |

4. Текст для **Cloud config** — впишите значения после `=`, ничего больше не меняйте:

   ```yaml
   #cloud-config
   write_files:
     - path: /opt/roi-dealer/secrets.env
       permissions: '0600'
       owner: root:root
       content: |
         TELEGRAM_BOT_TOKEN=
         TELEGRAM_OWNER_USER_ID=
         PUBLIC_CONTACT_EMAIL=
         GEMINIFREE_API_KEY=
         GEMINI_API_KEY=
         OPENAI_API_KEY=
         ANTHROPIC_API_KEY=
         LEMONSQUEEZY_WEBHOOK_SECRET=
   runcmd:
     - - bash
       - -c
       - curl -fsSL https://raw.githubusercontent.com/userpr0/roi-dealer/main/infra/hetzner/install.sh -o /root/roi-dealer-install.sh && bash /root/roi-dealer-install.sh > /var/log/roi-dealer-install.log 2>&1
   ```

   Пробелы в начале строк важны: вставляйте блок целиком. Тот же текст — в репозитории, `infra/hetzner/cloud-init.yaml`.

5. **Create & Buy now**. Пароль root придёт на почту — он нужен только для консоли Hetzner, сохраните его.

## 3. Проверьте (через 10 минут)

1. Бот пришлёт **«🟢 ROI Dealer bot запущен»** с версией.
2. `/decisions` → **«✅ Одобрить все доступы»** → проверьте список → **«✅ Да, одобрить все»**. База новая, поэтому доступы одобряются заново: Hacker News, Lemmy, агенты, «Сайт тестов».
3. `/status`:
   - `🟢 database: ok`;
   - AI — провайдеры с ✓;
   - «🧭 Запуск: всё настроено ✅».
4. Кнопка **«Пульт»** открывает панель.

Если через 20 минут бот молчит: Hetzner → сервер → **Power** → **Reboot**. Если и это не помогло — напишите Claude, что видите.

## 4. Railway

Когда панель Railway снова откроется: проект **bountiful-warmth** → **Settings** → **Danger** → **Delete project**, чтобы он больше не выставлял счёт. До этого старые сервисы безопасны:

- автоматика остановлена `/stop`;
- старый токен бота отозван.

## Повседневное

| Что                           | Как                                                                                                         |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Новая версия                  | Ничего: сервер ставит её сам через 5–10 минут после зелёного CI. Бот напишет «запущен» с новой версией      |
| Перезапуск                    | Hetzner → сервер → **Power** → **Reboot**. Данные сохраняются                                               |
| Копии базы                    | Сами: снимок диска Hetzner каждый день и копия базы каждую ночь на сервере (7 дней)                         |
| Адрес `api` (Пульт, страницы) | `https://<IP сервера через дефисы>.sslip.io`, например `https://203-0-113-7.sslip.io`. Бот получает его сам |

### Заменить ключ

1. Hetzner → сервер → кнопка **>\_** (**Console**).
2. Логин `root`, пароль — из письма Hetzner.
3. Введите `bash /opt/roi-dealer/app/infra/hetzner/set-key.sh` и нажмите Enter.
4. Введите имя переменной, например `GEMINI_API_KEY`, затем значение. Значение не отображается при вводе.

Скрипт перезапустит только те сервисы, которые используют этот ключ.
