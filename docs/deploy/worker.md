# Worker в облаке (Railway): сбор данных

> **Когда:** после вливания PR с PHASE 05, когда облачная PostgreSQL и бот уже работают ([database.md](database.md)).
> **Что делает worker:** раз в 15 минут проверяет источники из каталога (сейчас — Hacker News). Сначала просит у вас доступ в `/decisions`; после одобрения забирает новые посты (не чаще раза в час, не больше 30 за раз), вычищает контакты и ники и сохраняет Evidence. С AI-ключами (PHASE 09, [раздел 5](#ai-ключи-phase-09)) ещё вычищает имена людей.
> Интерфейс Railway меняется: если кнопка называется иначе, ищите ближайшую по смыслу.

## Сколько стоит

Worker почти всё время ждёт: обычно $1–3 в месяц. Вместе с ботом и базой — в пределах лимита инфраструктуры $20/мес (D-007). Лимиты расходов в Railway уже стоят.

## 1. Создать сервис (около 5 минут)

1. [railway.com/dashboard](https://railway.com/dashboard) → проект с ботом → **+ Create** → **GitHub Repo** → `userpr0/roi-dealer`.
2. Railway может создать несколько **новых** сервисов, по одному на каждое приложение репозитория:
   - оставьте один из них (он станет worker);
   - остальные новые удалите: сервис → **Settings** → внизу **Delete Service**.

   Прежний сервис бота с зелёным **Online** не трогайте. Если среди новых появился второй бот, удалите именно его: два бота с одним токеном мешают друг другу.

3. Новый сервис → **Settings** → вверху имя → `worker`.
4. **Variables** → **Raw Editor** → две строки → **Update Variables**:

   ```
   RAILWAY_DOCKERFILE_PATH=apps/worker/Dockerfile
   DATABASE_URL=${{Postgres.DATABASE_URL}}
   ```

   `DATABASE_URL` — ссылка на переменную базы: пароль не копируется руками и не попадает в чат.

5. **Settings** — как у бота:

   | Раздел     | Поле                           | Значение                                                          |
   | ---------- | ------------------------------ | ----------------------------------------------------------------- |
   | Source     | Root Directory                 | пусто                                                             |
   | Source     | Branch connected to production | `main`                                                            |
   | Source     | Wait for CI                    | включено                                                          |
   | Build      | Builder                        | Dockerfile (задаётся `RAILWAY_DOCKERFILE_PATH`)                   |
   | Build      | Custom Build Command           | пусто                                                             |
   | Build      | Watch Paths                    | пусто                                                             |
   | Deploy     | Pre-deploy Command             | `node /app/node_modules/@roi-dealer/database/dist/migrate-cli.js` |
   | Deploy     | Custom Start Command           | **пусто**                                                         |
   | Deploy     | Serverless                     | выключено — worker работает постоянно                             |
   | Scale      | Replicas                       | 1                                                                 |
   | Scale      | Replica Limits                 | 0.5 vCPU, 0.5 GB — защита бюджета                                 |
   | Networking | Public domain                  | не создавать                                                      |

   Миграции запускают и бот, и worker. Это безопасно: раннер берёт блокировку и пропускает уже применённые файлы.

6. Вверху **Apply N changes** → **Deploy**. Через 2–4 минуты карточка `worker` станет **Online**.

## 2. Одобрить источник

1. Telegram → `/decisions` → карточка **«Доступ: Hacker News»**.

   В карточке написано, что собирается и на каких условиях:
   - только посты Ask HN;
   - короткие цитаты без ников и контактов;
   - ничего не публикуется.

2. **✅ Одобрить** → **Да**.
3. Не позже чем через 15 минут worker заберёт первые посты.

Если отклонить карточку, источник отключится навсегда. Приостановить или отозвать доступ позже можно в `/access`.

## 3. Проверка

| Где                                  | Что должно быть                                                                                     |
| ------------------------------------ | --------------------------------------------------------------------------------------------------- |
| Railway → `worker` → **Deploy Logs** | `evidence collection scheduled`; до одобрения — `evidence collection skipped` с `access_not_active` |
| Telegram → `/decisions`              | Карточка «Доступ: Hacker News»                                                                      |
| После одобрения, логи                | `evidence collected` с числом элементов и замен (`redactions`)                                      |
| Telegram → `/journal` → **День**     | `Интеграция source:hacker-news · ➕ Доказательство ×N`                                              |
| Telegram → `/access`                 | Hacker News — активен, с кнопками ⏸ / ⛔                                                            |
| Дайджест в 10:00                     | Строка «📚 Новых доказательств за сутки: N»                                                         |

## 4. Остановить сбор

- **Всё сразу:** `/stop` в Telegram — стоп-кран останавливает и сбор.
- **Один источник:** `/access` → ⏸ (вернуть — ▶️) или ⛔ (навсегда).
- **Сам worker:** Railway → `worker` → **Settings** → **Remove** / **Delete Service**. Бот и данные не пострадают.

## AI-ключи (PHASE 09)

> **Когда:** после вливания PR с PHASE 09. Без ключей всё работает, только без AI: имена людей в Evidence не вычищаются.
> **Сколько:** в сумме не больше $50 в месяц (D-007). Код тратит не больше остатка месяца на оставшиеся дни и не больше $20 за день. Первый запуск прогоняет эталоны на трёх моделях — около $0.03.
> **Ключи никому не присылайте, в том числе в этот чат.** Только в Variables сервиса `worker`.

Можно подключить одного, двух или всех трёх провайдеров. Порядок моделей система выберет сама по эталонам (D-021).

### Claude (Anthropic) — около 5 минут

1. [console.anthropic.com](https://console.anthropic.com) → войти или создать аккаунт.
2. **Settings** → **Billing** → пополнить баланс, например на $20.
3. **Settings** → **Limits** → месячный лимит расходов — $20.
4. **API Keys** → **Create Key** → имя `roi-dealer-worker` → скопировать ключ. Он показывается один раз.

### GPT (OpenAI) — около 5 минут

1. [platform.openai.com](https://platform.openai.com) → войти.
2. **Settings** → **Billing** → пополнить баланс, например на $15.
3. **Settings** → **Limits** → месячный бюджет — $15.
4. **API keys** → **Create new secret key** → имя `roi-dealer-worker` → скопировать ключ.

### Gemini (Google) — около 7 минут

1. [aistudio.google.com](https://aistudio.google.com) → войти аккаунтом Google.
2. **Get API key** → **Create API key** → создать новый проект (например, `roi-dealer`).
3. Включить оплату для этого проекта (**Set up billing**, платный уровень).

   **Обязательно.** На бесплатном уровне Google может использовать запросы для улучшения своих продуктов.

4. Если в кабинете есть лимит расходов, поставьте $15.

   Бюджет в Google Cloud Billing (**Budgets & alerts**) только присылает оповещения. Жёсткий стоп стоит в коде ROI Dealer.

5. Скопировать ключ.

### Вписать ключи в Railway

1. Railway → `worker` → **Variables** → **Raw Editor** → добавить строки только для тех ключей, которые есть:

   ```
   ANTHROPIC_API_KEY=...
   OPENAI_API_KEY=...
   GEMINI_API_KEY=...
   ```

2. **Update Variables** → **Deploy**.

### Проверка

| Где                                  | Что должно быть                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------------------ |
| Railway → `worker` → **Deploy Logs** | `ai providers configured` со списком провайдеров, затем `ai models verified`                     |
| Те же логи, 1–3 минуты               | `ai eval passed` для каждой модели (`claude-haiku-5-5`, `gemini-3.1-flash-lite`, `gpt-5.4-mini`) |
| Telegram → `/status`                 | «🤖 AI сегодня: $… из $… · за месяц $… из $50» и Claude / GPT / Gemini с ✓                       |
| Дайджест в 10:00                     | Строка «🤖 AI за сутки: …»                                                                       |

### Агент болей и сигналов (PHASE 06)

1. Когда в worker появились ключи, через 1–3 минуты в `/decisions` придёт карточка **«Доступ: Агент болей и сигналов»**.
   Агент:
   - читает новые доказательства;
   - находит в них боли;
   - группирует похожие.

   Решений и денег он не касается.

2. Нажмите **✅ Одобрить** → **Да**.
3. Не позже чем через 15 минут:
   - в логах появится `pain analysis` с числом сигналов;
   - в Telegram — список болей по `/pains`.

Остановить агента можно в `/access` (⏸ / ⛔) или стоп-краном `/stop`.

### Агент возможностей (PHASE 07)

1. Вместе с агентом болей в `/decisions` придёт карточка **«Доступ: Агент возможностей»**.
   Агент:
   - берёт боли, которые встретились хотя бы дважды;
   - формулирует возможность;
   - отмечает признаки готовности платить.

   Оценку и бизнес-модель считает код. Агент создаёт только черновики.

2. Нажмите **✅ Одобрить** → **Да**.
3. Когда у болей наберётся по 2 сигнала:
   - в логах появится `opportunity assessment`;
   - в Telegram — список по `/opportunities` с оценкой 0–100.

### Агент исследований и агент рыночного контекста (PHASE 10)

1. Вместе с остальными в `/decisions` придут две карточки:
   - **«Доступ: Агент исследований»** — для болей, у которых мало сигналов, ищет похожие посты Ask HN через поиск Hacker News (HN Search API, Algolia); до 3 запросов за 6 часов. Посты сохраняет интеграция Hacker News с той же очисткой;
   - **«Доступ: Агент рыночного контекста»** — для черновиков возможностей собирает из доказательств, чем люди решают проблему сейчас, какие суммы называют и кто платит. Только с цитатами; суммы считает код.
2. Нажмите **✅ Одобрить** → **Да** на обеих.
3. Через 6 часов (первый запуск — сразу после старта worker):
   - в логах — `research` и `market context`;
   - в Telegram — строка «Рынок: …» у возможностей в `/opportunities`;
   - `/agents` — все агенты: доступ, последний запуск, сутки и стоимость AI.

Интервалы меняются переменными `RESEARCH_INTERVAL_MS` и `MARKET_INTERVAL_MS` (по умолчанию 6 часов); `SIGNALS_INTERVAL_MS` — 15 минут, `OPPORTUNITIES_INTERVAL_MS` — час.

### Если что-то не так

| В логах                                          | Что значит и что сделать                                                               |
| ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| `ai eval not completed` с `code: unavailable`    | Ключ не подходит или модель недоступна аккаунту. Проверьте ключ и оплату у провайдера  |
| `ai models verified` с `false` у модели          | Провайдер не даёт эту модель. Остальные работают; напишите Claude — он обновит реестр  |
| `ai eval failed`                                 | Модель не прошла эталон и не используется. Ничего делать не нужно                      |
| `name redaction unavailable: rules only`         | AI недоступен или квота дня закончилась. Сбор продолжается с очисткой правилами        |
| `pain analysis` с `stopped_by: budget`           | Доля дня на поиск болей закончилась. Остальные доказательства разберутся завтра        |
| `agent run` с `outcome: no_access`               | Агент ждёт одобрения в `/decisions` или приостановлен в `/access`                      |
| `research skipped: the source is not granted`    | Агенту исследований нужен одобренный доступ Hacker News («Доступ: Hacker News»)        |
| `agent run` с `outcome: failed` и `code`         | Ошибка запуска агента; следующий запуск — по расписанию. Повторяется — напишите Claude |
| `opportunity assessment skipped` с `nothing_new` | Нет болей с 2 сигналами, или все уже оценены. Нужно больше данных                      |

**Выключить AI:** удалить ключ из Variables → **Deploy**. Утечка ключа — по [runbook](../runbooks/secret-leak.md): отозвать ключ в кабинете провайдера и создать новый.
