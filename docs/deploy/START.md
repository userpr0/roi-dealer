# Запуск ROI Dealer: что сделать владельцу

> Одна страница, около 20 минут, по порядку. Всё, что не требует ваших аккаунтов и секретов, уже сделано (D-023). Блоки ниже вставляются как есть, кроме значений, которые вписываете вы.
> **Секреты (ключи AI, секрет webhook) — только в Variables Railway. В чат не присылать никому, в том числе Claude.**

## Уже сделано за вас

- **Код влит в `main`** (фазы 05–20b и 13c): бот обновлён, миграции применены. `/status` — `🟢 database: ok`.
- **`/status` сам показывает, что осталось.** Чек-лист «🧭 Запуск» — что не настроено и какой шаг ниже. Когда всё готово, бот один раз пишет «✅ Всё настроено».
- **Сторож.** Если `worker` или `api` перестанут работать, после деплоя останутся на старой версии или ключ AI не примут, бот сам напишет, что случилось и где смотреть. Когда починится — тоже напишет.
- **Кнопка «Пульт» (Mini App).** Бот ставит её сам, как только узнает адрес `api` (шаг 4). Переменная GitHub и @BotFather не нужны.
- **Доступы одобряются одной кнопкой.** В `/decisions` — «✅ Одобрить все доступы (N)». Бот покажет весь список и одобрит ровно его.
- **Почему сервисы Railway создаёте вы.** У Claude нет доступа к вашему аккаунту Railway. Файлы настроек сервисов (Config as Code) Railway для новых сервисов больше не принимает. Поэтому ниже — готовые блоки для вставки.

## 1. Подготовка в Railway (1 минута)

1. [railway.com/dashboard](https://railway.com/dashboard) → проект с ботом.
2. Сервис бота → **Settings** → вверху имя → **`bot`**. Тогда ссылки `${{bot.…}}` ниже сработают без правок.
3. **Postgres** → **Backups** → включить ежедневные копии.

## 2. Сервис `worker` — сбор данных и агенты (5 минут)

1. **+ Create** → **GitHub Repo** → `userpr0/roi-dealer`.

   Railway может создать несколько новых сервисов. Оставьте один, остальные новые удалите: **Settings** → внизу **Delete Service**. Сервис `bot` с **Online** не трогайте.

2. **Settings** → имя → `worker`.
3. **Variables** → **Raw Editor** → вставьте блок → впишите ключи AI после `=` → **Update Variables**:

   ```
   RAILWAY_DOCKERFILE_PATH=apps/worker/Dockerfile
   DATABASE_URL=${{Postgres.DATABASE_URL}}
   ANTHROPIC_API_KEY=
   OPENAI_API_KEY=
   GEMINI_API_KEY=
   ```

   - Нужен хотя бы один ключ, лучше все три ([где взять](worker.md#ai-ключи-phase-09)).
   - Лимиты в кабинетах провайдеров — в сумме не больше $50/мес.
   - Пустой ключ система просто не использует.
   - Чтобы ключ больше не показывался в Railway: **⋮** у переменной → **Seal**.

4. **Settings**:

   | Поле                          | Значение                                                          |
   | ----------------------------- | ----------------------------------------------------------------- |
   | Source → Wait for CI          | включено                                                          |
   | Build → Custom Build Command  | пусто (если Railway подставил команду — удалить)                  |
   | Deploy → Pre-deploy Command   | `node /app/node_modules/@roi-dealer/database/dist/migrate-cli.js` |
   | Deploy → Custom Start Command | пусто                                                             |
   | Scale → Replica Limits        | 0.5 vCPU, 0.5 GB                                                  |
   | Networking                    | домен не нужен                                                    |

5. Вверху **Apply changes** → **Deploy**. Через 2–4 минуты — **Online**.

## 3. Сервис `api` — пульт, страницы тестов, заявки, оплаты (5 минут)

1. Так же: **+ Create** → **GitHub Repo** → `userpr0/roi-dealer`. Лишние новые сервисы удалите.
2. **Settings** → имя → `api`.
3. **Variables** → **Raw Editor** → вставьте блок → впишите свою почту → **Update Variables**:

   ```
   RAILWAY_DOCKERFILE_PATH=apps/api/Dockerfile
   DATABASE_URL=${{Postgres.DATABASE_URL}}
   TELEGRAM_BOT_TOKEN=${{bot.TELEGRAM_BOT_TOKEN}}
   TELEGRAM_OWNER_USER_ID=${{bot.TELEGRAM_OWNER_USER_ID}}
   PUBLIC_CONTACT_EMAIL=
   ```

   - `PUBLIC_CONTACT_EMAIL` — почта, на которую люди пишут об удалении своих данных. Она видна на странице `/privacy`. Без неё на страницах тестов нет формы заявки.
   - Токен бота — ссылкой, руками не копируется. `api` только проверяет им подпись Telegram.

4. **Settings**:

   | Поле                          | Значение                                |
   | ----------------------------- | --------------------------------------- |
   | Source → Wait for CI          | включено                                |
   | Build → Custom Build Command  | пусто                                   |
   | Deploy → Pre-deploy Command   | пусто — миграции запускают бот и worker |
   | Deploy → Custom Start Command | пусто                                   |
   | Deploy → Healthcheck Path     | `/health`                               |
   | Scale → Replica Limits        | 0.5 vCPU, 0.5 GB                        |
   | Networking                    | **Generate Domain**, порт `8080`        |

5. **Apply changes** → **Deploy**. Через 2–4 минуты — **Online**.

## 4. Бот узнаёт адрес `api` (1 минута)

Когда у `api` появился домен (шаг 3.4): сервис `bot` → **Variables** → **Raw Editor** → добавьте строку → **Update Variables**:

```
PUBLIC_API_URL=https://${{api.RAILWAY_PUBLIC_DOMAIN}}
```

Бот перезапустится и сам:

- поставит слева от поля ввода кнопку **«Пульт»** — Mini App с данными из `api`;
- начнёт присылать в карточках лендингов ссылки на предпросмотр и на опубликованную страницу.

Если домен у `api` сменится, адрес обновится сам.

## 5. Одобрить доступы (1 минута)

Через 5–15 минут после запуска `worker` и `api`: `/decisions` → **«✅ Одобрить все доступы (N)»** → проверьте список → **«✅ Да, одобрить все»**.

В списке будут:

- **Hacker News** — сбор постов;
- **агенты** — боли и сигналы, возможности, исследования, рыночный контекст, судьи, гипотезы, автор лендингов;
- **Сайт тестов** — счётчик страниц и форма заявки.

Каждый доступ можно приостановить или отозвать в `/access`. Поздние карточки (например, «Платежи Lemon Squeezy») одобряются так же.

## 6. Проверка (2 минуты)

| Где                   | Что должно быть                                                      |
| --------------------- | -------------------------------------------------------------------- |
| `/status`             | `🟢 database: ok`, AI: провайдеры с ✓, «🧭 Запуск: всё настроено ✅» |
| Кнопка **«Пульт»**    | Стоп-кран, «Ждут решения», деньги месяца, тесты, цикл                |
| `/agents`             | Агенты с доступом, запуски без ошибок                                |
| `/access`             | Hacker News, агенты и «Сайт тестов» — 🟢 активен                     |
| `<адрес api>/privacy` | Страница с вашей почтой (адрес — в **Networking** сервиса `api`)     |
| Дайджест в 10:00      | Сводка за сутки; по понедельникам — недельный разбор                 |

## Что дальше происходит само

```text
посты (HN) → боли → возможность → судьи → карточка «⚖️ Возможность» → вы: ✅ Проверять
→ 5 гипотез → вы: /hypotheses → 🧪 выбрать → /experiments: ☑️ чек-лист → 🚀 запрос запуска → ✅ в /decisions
→ «🎨 Лендинг» приходит сам → вы: ✅ → 🚦 Release Gate → 🚀 Выпустить → ссылка для рекламы
→ вы: реклама по ссылке → ▶️ Тест запущен → просмотры, клики, заявки, оплаты считаются сами
→ /funnel: показы и траты с площадки → /leads: связаться, клиент, итог → 🏁 Итог теста
```

Ваши решения — только кнопками. Деньги на рекламу вы тратите сами на площадке, в бюджете, одобренном в `/decisions`.

## Платный предзаказ: Lemon Squeezy (около 20 минут, когда понадобится)

Нужен, только если тест — платный предзаказ (`/hypotheses` → «предзаказ»). Подробно — [api.md §7](api.md#7-оплаты-lemon-squeezy-phase-20b), решение — [ADR-0009](../ADR/0009-payments-merchant-of-record.md).

1. Аккаунт [Lemon Squeezy](https://www.lemonsqueezy.com/) → магазин. Условия и выплаты в вашу страну проверяются при регистрации.
2. Товар с ценой из гипотезы → **Share** → ссылка вида `https://<магазин>.lemonsqueezy.com/buy/…`. Сначала — в **Test mode**.
3. Придумайте секрет: 16+ случайных символов (например, из менеджера паролей).
4. Lemon Squeezy → **Settings → Webhooks → +**:
   - адрес — `<адрес api>/webhooks/lemonsqueezy`;
   - события — `order_created` и `order_refunded`;
   - секрет — из шага 3.
5. Railway → `api` → **Variables** → **+ New Variable** → `LEMONSQUEEZY_WEBHOOK_SECRET` = тот же секрет.
6. `/decisions` → «Доступ: Платежи Lemon Squeezy» → ✅.
7. `/checkout <№ теста> <ссылка Test mode>` → откройте страницу теста, нажмите кнопку → тестовая покупка картой `4242 4242 4242 4242`. Бот напишет «✅ Тестовый платёж дошёл».
8. Боевой режим магазина → `/checkout <№ теста> <боевая ссылка>` → Release Gate пропустит предзаказ.

## Если что-то не так

| Что видно                                          | Что сделать                                                                                              |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| В Variables ссылка `${{bot.…}}` красная или пустая | Сервис бота называется не `bot` — переименуйте (шаг 1.2) или выберите переменную в подсказке после `${{` |
| Нет кнопки «Пульт»                                 | У бота нет `PUBLIC_API_URL` или у `api` ещё нет домена — шаг 4; бот должен перезапуститься               |
| Пульт: «Подпись Telegram не принята»               | У `api` другой токен — проверьте `TELEGRAM_BOT_TOKEN=${{bot.TELEGRAM_BOT_TOKEN}}`                        |
| Сервис упал на сборке с `npm` / `railpack`         | Не задан `RAILWAY_DOCKERFILE_PATH` или осталась Custom Build/Start Command — шаги 2.3–2.4 / 3.3–3.4      |
| Подробнее                                          | [worker.md](worker.md), [api.md](api.md), [telegram-bot.md](telegram-bot.md), [database.md](database.md) |

## Деньги

- **Инфраструктура** (бот, worker, api, Postgres в Railway) — до $20/мес (D-007). Счета вносите командой `/cost 5 инфраструктура Railway …`.
- **AI** — до $50/мес: жёсткий стоп в коде и лимиты в кабинетах.
- **Реклама** — бюджет каждого теста одобряете в `/decisions`, траты вносите через `/funnel … $траты`. Stop-loss останавливает тест сам.
- **Стоп-кран** — `/stop`: все автоматизации и записи встают; `/resume` — продолжить.
