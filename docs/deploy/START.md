# Запуск ROI Dealer: что сделать владельцу

> Одна страница: всё, что нужно сделать после вливания PR, чтобы система заработала целиком — от сбора данных до оплат. Подробности — по ссылкам.
> **Секреты (токены, ключи, секрет webhook) — только в Variables Railway. В чат не присылать никому, в том числе Claude.**

GitHub → [pull requests](https://github.com/userpr0/roi-dealer/pulls) → PR с фазами 05–20b → **Merge**. Бот в Railway обновится сам после зелёного CI и применит миграции.

## 3. Одобрить доступы в `/decisions` (5 минут)

Карточки «Доступ: …» приходят сами, когда сервис запущен. На каждую — **✅ Одобрить** → **Да**:

1. **Hacker News** — сбор постов (worker);
2. агенты (worker, после ключей AI): **болей и сигналов**, **возможностей**, **исследований**, **рыночного контекста**, **судьи**, **гипотез**, **Автор лендингов**;
3. **Сайт тестов** — счётчик страниц и форма заявки (`api`);
4. **Платежи Lemon Squeezy** — оплаты (`api`, после секрета webhook).

## 4. Что дальше происходит само

```text
посты (HN) → боли → возможность → судьи → карточка «⚖️ Возможность» → вы: ✅ Проверять
→ 5 гипотез → вы: /hypotheses → 🧪 выбрать → /experiments: ☑️ чек-лист → 🚀 запрос запуска → ✅ в /decisions
→ «🎨 Лендинг» приходит сам → вы: ✅ → 🚦 Release Gate → 🚀 Выпустить → ссылка для рекламы
→ вы: реклама по ссылке → ▶️ Тест запущен → просмотры, клики, заявки, оплаты считаются сами
→ /funnel: показы и траты с площадки → /leads: связаться, клиент, итог → 🏁 Итог теста
```

Ваши решения — только кнопками; деньги на рекламу тратите вы сами на площадке, в бюджете, одобренном в `/decisions`.

## 5. Платный предзаказ: Lemon Squeezy (около 20 минут, когда понадобится)

Нужен, только если тест — платный предзаказ (`/hypotheses` → «предзаказ»). Подробно — [api.md §7](api.md#7-оплаты-lemon-squeezy-phase-20b), решение — [ADR-0009](../ADR/0009-payments-merchant-of-record.md).

1. Аккаунт [Lemon Squeezy](https://www.lemonsqueezy.com/): магазин; условия и выплаты в вашу страну проверяются при регистрации.
2. Товар с ценой из гипотезы → ссылка на оплату (**Share** → ссылка вида `https://<магазин>.lemonsqueezy.com/buy/…`), сначала в **Test mode**.
3. **Settings → Webhooks → +**: адрес `<адрес api>/webhooks/lemonsqueezy`, события `order_created` и `order_refunded`, свой секрет 16+ символов → он же в `LEMONSQUEEZY_WEBHOOK_SECRET` у `api`.
4. `/decisions` → «Доступ: Платежи Lemon Squeezy» → ✅.
5. `/checkout <№ теста> <ссылка Test mode>` → откройте страницу теста, кнопка → тестовая покупка (карта `4242 4242 4242 4242`) → бот: «✅ Тестовый платёж дошёл».
6. Боевой режим магазина → `/checkout <№ теста> <боевая ссылка>` → Release Gate пропустит предзаказ.

## 7. Деньги

- **Инфраструктура** (бот, worker, api, Postgres в Railway) — до $20/мес (D-007); счета вносите `/cost 5 инфраструктура Railway …`.
- **AI** — до $50/мес: жёсткий стоп в коде и лимиты в кабинетах.
- **Реклама** — бюджет каждого теста одобряете в `/decisions`; траты вносите `/funnel … $траты`; stop-loss останавливает тест сам.
- **Стоп-кран** — `/stop`: все автоматизации и записи встают; `/resume` — продолжить.
