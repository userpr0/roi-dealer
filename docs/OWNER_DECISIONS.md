# Решения владельца

Журнал решений владельца, которые влияют на архитектуру, политику и приоритеты. Новые решения добавляются сверху; старые не удаляются — изменение оформляется новой записью со ссылкой на прежнюю.

Реализация обязана следовать этим решениям. Если решение противоречит конституции или ADR — остановиться и спросить владельца.
