# 35 REPORT — Библиотека «вертикаль → проект → тема» (минимальная)

> **Спецификация:** [35_library.md](35_library.md). **Основание:** D-040, D-043, [ADR-0016](../ADR/0016-library-and-own-assets.md), часть 1. **Статус:** PASS — шаги 1–6; шаг 7 (выгрузка) — после $1 000 в месяц (D-043). Сделана раньше фазы 36: объекты фазы 36 кладутся в библиотеку (ADR-0016, п. 8), а код библиотеки уже был готов черновиком (`a2ebbae`).

## Implemented

- **Миграция `0028_library`:** дерево `library_verticals` → `library_projects` → `library_topics` (версии, события, имя уникально в родителе без учёта регистра и «ё»); журнал `library_filings` только для добавления.
- **Домен:** фабрики узлов, `planLibraryPlace` (имена и лимиты дерева: 20 вертикалей, 50 проектов, 200 тем), `newLibraryNodes`, `libraryPath`; архивирует и возвращает тему только владелец.
- **AI-задача `file-library`** (bulk, без персональных данных, 23 эталона): модель называет существующую тему ключом или новое место; код проверяет имена и переиспользует узлы с тем же именем.
- **Агент `librarian`** — каждые 30 минут (`LIBRARY_INTERVAL_MS`): раскладывает новые боли, каждую версию один раз (`agent_work`); возможность кладёт туда же, где её первая боль, без AI; переносы владельца видит как примеры. Доступ — по карточке в `/decisions`.
- **Пульт:** `/library` — дерево кнопками; «Переложить» (вертикаль → тема → подтверждение) — новая строка журнала от владельца; `/library add Вертикаль / Проект / Тема` — с подтверждением. Строка дайджеста «📚 Новое в библиотеке за сутки».

## Tests

- **Unit:** имена и их сравнение; кто создаёт и кто архивирует; переиспользование узлов, новая ветка, лимиты дерева; разбор ответа модели; эталоны `file-library` (идеальная модель проходит, ленивая — нет); вход модели — ближайшие темы и примеры переносов.
- **Integration:** доступ до работы; раскладка в новое место и возможность рядом с болью; похожая боль — в ту же тему по ключу; плохой ответ — один раз `rejected`, без повторного вызова AI; строка дайджеста; добавление папки и перенос через настоящий роутер бота, повторное нажатие ничего не меняет; журнал не правится; имя уникально без учёта регистра.
- `pnpm test`: 104 файла, 976 тестов — PASS; `typecheck`, `lint`, `format:check` — PASS.
