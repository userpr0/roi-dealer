# PHASE 05 — Evidence Engine: требования владельца

> **Статус:** backlog требований (D-014, пункты 5–6). Реализация — в PHASE 05 после approval владельца; спецификация фазы обязана включить эти требования.
> **Принципы:** §2.5 Evidence First, §2.20 «паттерн, а не копия», §2.21 «только разрешённый доступ».

## 1. Каталог источников данных (D-014 п.5)

Прежде чем подключить источник, он вносится в каталог — по той же схеме, что реестр провайдеров в Media Factory ([план PHASE 19](19_media_factory.plan.md)). Источник без записи в каталоге не подключается.

| Поле каталога            | Зачем                                                                                                                                                                                                |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Способ доступа           | Официальный API / RSS / выгрузка / ручной ввод. Скрейпинг в нарушение условий площадки запрещён (§2.21)                                                                                              |
| Условия использования    | Разрешено ли коммерческое использование, нужна ли отдельная договорённость (например, коммерческое использование Reddit API, как правило, требует отдельного соглашения — проверить при подключении) |
| Стоимость                | Бесплатный лимит, тариф, цена за запрос                                                                                                                                                              |
| Лимиты                   | Rate limits, квоты, окно данных                                                                                                                                                                      |
| Поля данных              | Что источник отдаёт и что из этого нам нужно                                                                                                                                                         |
| Риск персональных данных | Есть ли в данных имена, ники, контакты (→ п.6)                                                                                                                                                       |
| Рынки и язык             | Для старта — США и англоязычные Tier-1 (D-008)                                                                                                                                                       |
| Надёжность и доверие     | Уровень доверия по умолчанию для Evidence                                                                                                                                                            |
| Статус проверки          | Кто и когда проверил условия; ссылка на снимок условий                                                                                                                                               |

Требование к порядку работы: сначала каталог и проверка условий, потом код коннектора.

## 2. Приватность и минимизация данных (D-014 п.6)

- В Evidence сохраняются цитата или агрегат, источник, время и рынок. **Не** сохраняются имена, ники, ссылки на профили, email, телефоны, если без них можно обойтись.
- Контакты и идентификаторы в тексте вычищаются (редактирование) до сохранения.
- Срок хранения сырых снимков ограничен; долго хранятся только извлечённые факты и паттерны.
- Процесс удаления по запросу человека (CCPA / GDPR) описывается до сбора данных с рынков США и Европы.
- Никаких действий от имени пользователей площадок и никакой рассылки людям, найденным в источниках, без их согласия.

## Критерии готовности (добавить в спецификацию PHASE 05)

1. Каждый подключённый источник есть в каталоге с проверенными условиями.
2. Коннектор отказывается работать с источником без записи в каталоге.
3. Тесты подтверждают, что персональные данные вычищаются из Evidence.
