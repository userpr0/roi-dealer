# 27 REPORT — «Лист наблюдения»

> **Спецификация:** [27_watchlist.md](27_watchlist.md). **Основание:** D-035, ADR-0013. **Статус:** PASS.

## Implemented

- `@roi-dealer/domain`: `watchGrowth` (вдвое больше сигналов из нового источника; после «оставить» — вдвое от того уровня).
- `database.watchlist`: `decide`, `decisions`, `falseRejections`; миграция `0025_watchlist`.
- Пульт: `/watchlist` (отклонённые боли и боли закрытых возможностей, похожие новые боли, рост, кнопки «Вернуть» / «Оставить» с подтверждением), строка в дайджесте.

## Tests

- Unit: правило роста, те же источники и мало сигналов, повтор после «оставить».
- Integration: отсечённая боль → похожая новая из нового источника → вопрос в `/watchlist` и дайджесте → возврат кнопкой с подтверждением → больше не спрашивает; журнал не правится.
- `pnpm test`: 100 файлов, 949 тестов — PASS; `typecheck`, `lint`, `format:check` — PASS.

## Not implemented (Feature Kill Gate)

- «Пульс» и новые площадки как сигнал роста — после связи «Пульса» с болями.
- Ложные отказы в весах — вместе с предложением новых весов (фаза 25).
