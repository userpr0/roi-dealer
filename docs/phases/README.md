# Phases

Каждая Phase выполняется отдельно: спецификация → реализация → тесты → Phase Report → approval владельца → следующая Phase. По D-020 все фазы до полного Уровня 2 одобрены сразу, в порядке [`ROADMAP.md`](../ROADMAP.md): Claude идёт без остановок между ними и останавливается только ради действий владельца, ADR сверх плана, денег сверх лимитов и Уровня 3.
Спецификация Phase хранится здесь как `NN_short_name.md`, отчёт — `NN_short_name.report.md`.
