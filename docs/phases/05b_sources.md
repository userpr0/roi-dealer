## Objective

Боль подтверждается, только когда её видно в двух источниках (`MIN_SOURCES_FOR_VALIDATED_PAIN`). Сейчас источник один — Hacker News, поэтому все боли остаются кандидатами. Часть 1 подключает второй источник болей, для которого не нужен ни ключ, ни договор, ни действие владельца, кроме одобрения доступа в `/decisions`.

Из разрешённых источников болей это **Lemmy (lemmy.world)**: условия распространяются на API и разрешают пользоваться им «in good faith», ключ не нужен. Bluesky тоже разрешён, но ему нужны пароль приложения владельца и способ удалять фрагмент по просьбе автора — это часть 2.

## Scope

### 1. Коннектор `createLemmyConnector` (`@roi-dealer/evidence`)

- Официальный API lemmy.world `GET /api/v3/post/list`: новые посты сообществ, где люди спрашивают и описывают проблемы — `asklemmy`, `nostupidquestions`, `selfhosted`. По 20 постов на сообщество за раз.
- **Берёт только посты, созданные на lemmy.world** (`local`). Копии постов с других серверов Lemmy подчиняются условиям тех серверов — так записано в каталоге.
- Пропускает удалённые, снятые модераторами и NSFW посты, а также посты не на английском (оставляет английский и «язык не указан»).
- Автора не читает и не хранит: поле `creator` не входит в схему ответа. Текст — заголовок и тело поста, дальше обычная очистка персональных данных движка (`redactPersonalData`, затем вычистка имён AI).
- Ссылка — на пост на lemmy.world. Уже сохранённые посты повторно не берёт (`known`).
- Ошибки сети и неожиданный ответ — `fetch_failed` / `bad_response`, как у Hacker News: сбой источника не останавливает worker.

### 2. Worker

- `createEvidenceScheduler` получает второй коннектор. Адрес API — `LEMMY_API_URL` (по умолчанию lemmy.world; тесты подставляют локальный фейк).
- Лимиты — из каталога: не чаще раза в час, до 30 постов за загрузку. robots.txt lemmy.world просит `Crawl-delay: 60`; три запроса раз в час его не нарушают.
- Как и у Hacker News, источник сначала просит доступ в `/decisions` («Lemmy (lemmy.world)») и ничего не загружает, пока владелец не одобрит.

### 3. Каталог

Условие записи `lemmy-world`: только посты, созданные на lemmy.world. Лимит провайдера: явных лимитов нет, `Crawl-delay: 60` в robots.txt.

## Out of scope

- **Bluesky** — часть 2: пароль приложения владельца, удаление фрагмента по просьбе автора, публичный контакт.
- **Ряды чисел** (Википедия, npm, PyPI, статистика) — часть 3: нужно решение, как хранить ряды и как они входят в оценку возможности (`05b_sources.plan.md`, «Решить в спецификации»). Это новая модель данных — сначала ADR.
- **Поиск по Lemmy для агента исследований** — не нужен: агенту хватает поиска по Hacker News, а robots.txt lemmy.world закрывает `/search/`.

## Acceptance criteria

1. Коннектор берёт новые посты трёх сообществ и пропускает чужие, удалённые, снятые, NSFW и неанглийские.
2. Автор не попадает ни в Evidence, ни в логи; текст проходит очистку движка.
3. Повторная загрузка не берёт сохранённые посты; ошибки источника дают `fetch_failed` / `bad_response`.
4. Worker с `LEMMY_API_URL` просит доступ для Lemmy и после одобрения сохраняет посты как Evidence.
5. `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `pnpm test`, `pnpm build` — зелёные.

## Действия владельца

После деплоя: `/decisions` → «Доступ: Lemmy (lemmy.world)» → ✅ → **Да**. Ключи и переменные не нужны.
