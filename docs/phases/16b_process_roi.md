# 16b — «ROI процесса»: что сколько стоило и что дало

> **Статус:** реализована ([отчёт](16b_process_roi.report.md)).
> **Основание:** [ADR-0011](../ADR/0011-closed-loop-with-gen-content.md) (D-030), этап G ROADMAP; запуск — «Начинай!» владельца.
> **Принципы:** §2.13 — числа считает код; §2.15 — Feature Kill Gate; решения — за владельцем.

## Зачем

Каждый месяц видно, какой процесс цикла тратит деньги и что даёт. Лишний процесс убирается по цифрам, а не по догадке; окупающийся — масштабируется.

## Процессы и их результат

| Процесс              | Расход                                                                                  | Результат                          |
| -------------------- | --------------------------------------------------------------------------------------- | ---------------------------------- |
| Поиск болей          | AI: `extract-signal`, `match-pain`, `redact-names`, `research-query`                    | подтверждённые боли                |
| Оценка возможностей  | AI: `frame-opportunity`, `market-context`, `judge-opportunity`                          | возможности, одобренные владельцем |
| Гипотезы и лендинги  | AI: `design-hypotheses`, `write-landing`; журнал: `media`                               | одобренные лендинги                |
| Тесты: трафик        | журнал: `ads`                                                                           | заявки и выручка                   |
| Проверка качества AI | AI: эталоны (`eval`)                                                                    | — общие расходы                    |
| Платформа            | журнал: инфраструктура, хранение, API, подрядчики, люди, прочее; AI-задачи без процесса | — общие расходы, лимит D-007       |

Расход AI — из журнала вызовов (ежедневные записи `ai` его повторяют); возвраты уменьшают выручку, а не расход.

## Вердикт (код)

- **➖ рано судить** — процесс потратил меньше $1.
- **🔻 пересмотреть или выключить** — потратил и не дал результата.
- **✅ оставить** — есть результат; показана цена одного.
- **📈 масштабировать** — тесты: выручка не меньше расхода.
- **🔻 выше лимита D-007** — платформа: инфраструктура выше месячного лимита.
- **ℹ️ общие расходы** — эталоны и платформа.

## Что видит владелец

- `/roi` — текущий месяц; `/roi прошлый` — прошлый месяц целиком.
- 1-го числа дайджест напоминает: «📊 Месяц закрыт: ROI процессов → /roi прошлый».
- Решает владелец: выключить агентов процесса — `/access`, всё сразу — `/stop`.

## Feature Kill Gate

Кнопок «убрать / масштабировать» в первой версии нет: решения выполняются существующими командами. Кнопки — когда месяц-другой данных покажет, что их не хватает. Связь с роликами Gen_Content (стоимость и итог каждого ролика) — в фазе 24.
