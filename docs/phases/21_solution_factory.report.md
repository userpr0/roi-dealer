## Implemented

- **Release Gate §7.2** (`releaseGate`, домен) — проверки кодом по данным базы:
  - лендинг одобрен;
  - запуск теста одобрен (бюджет, stop-loss, лимиты);
  - метрика — шаг воронки, stop-loss задан;
  - чек-лист честной проверки подтверждён;
  - счётчик воронки активен;
  - страница без скриптов и внешних адресов (`isStaticPage` на собранной странице);
  - для платного предзаказа — проверенная оплата (PHASE 20b) и пометка о возврате.

  Пункты, которые подтверждает владелец: Early User Crash Test и «известных блокирующих ошибок нет».

- **Выпуск** (`releaseMediaAsset`): только владелец, только одобренный лендинг, при пройденном Gate и обоих подтверждениях; время выпуска и подтверждения — в `MediaAsset` и в базе (миграция `0016`).
- **Публичная страница на `api`:**
  - `GET /l/<slug>` — страница, пока запуск одобрен или тест идёт;
  - `GET /l/<slug>/go` — нажатие кнопки → 303 на `/l/<slug>/thanks`, честная страница «продукт ещё не готов, ничего не собрано»;
  - тест закончился — 410 «тест завершён»; не выпущена — 404;
  - UTM-метки переходят в ссылку кнопки.
- **Счётчик воронки** (`createSiteTracker`, интеграция «Сайт тестов» `integration:site`):
  - `attention` — просмотр, `cta_click` — нажатие; только пока тест идёт;
  - один посетитель — один раз за 30 минут на шаг (солёный хеш в памяти);
  - роботы, превью ссылок, предзагрузка и `HEAD` не считаются; не больше 600 событий в минуту;
  - стоп-кран и приостановленный доступ останавливают запись — страница открывается;
  - доступ запрашивает `api` при старте и раз в 6 часов, пока владелец не решил.
- **Права:** новое `funnel.track` у интеграций; журнал воронки проверяет право по источнику события и активную личность — интеграция не может внести цифры владельца.
- **Пульт:**
  - у одобренного лендинга — **🚦 Release Gate**: ✅ / ❌ с тем, что исправить; всё ✅ → **🚀 Да, выпустить** с пунктами владельца → одна команда;
  - после выпуска — ссылка на страницу и ссылка для рекламы с UTM;
  - в `/experiments` — строка «🎨 Лендинг: 🌐 опубликован — /l/…» и кнопка **🎨 Лендинг** к карточке, пока лендинг ждёт вас;
  - **▶️ Тест запущен** у теста с лендингом в системе — только после выпуска;
  - `/funnel` не принимает «внимание» и «клики CTA» у теста с выпущенной страницей.
- **Логи `api`:** путь предпросмотра — `/p/:token`; адрес посетителя, браузер и UTM не логируются.

## Security implications

- **Нет трафика без проверки:** публичная страница появляется только после Gate и решения владельца; тест не запускается раньше.
- **Страница ничего не исполняет и не собирает:** без скриптов, cookies и форм; CSP `default-src 'none'`.
- **Приватность посетителей:** IP и браузер используются только в памяти для проверки повтора (хеш с солью процесса) и не хранятся и не логируются.
- **Накрутка:** повтор, роботы и предзагрузка не считаются; предел событий в минуту. Подмена `X-Forwarded-For` не обходит его: берётся адрес, который добавил прокси.
- **Права:** интеграция пишет только события своих страниц и только с активным доступом, который выдаёт владелец; стоп-кран останавливает запись.
- **Логи:** закрытая ссылка предпросмотра больше не попадает в журнал запросов.

## Cost implications

- **$0 сверх плана:** страницы отдаёт тот же сервис `api`; одна запись в базу на просмотр.

## Known limitations

- **Адрес страницы — домен Railway:** свой домен — когда понадобится (§2.15).
- **Счётчик в памяти процесса:** после перезапуска `api` тот же посетитель может быть посчитан ещё раз; при одной реплике это не искажает тест.
- **После нажатия пока «спасибо»:** форма заявки — PHASE 20, оплата — PHASE 20b.

## Architecture deviations

- Нет. Счётчик — источник `tracker` единой воронки (ADR-0007); страницы — в `@roi-dealer/site`, `apps/api` только связывает маршруты.

## Scope decisions

- **Страница открыта уже при одобренном запуске:** crash test проходит на настоящей странице, но в воронку попадает только трафик после старта.
- **Завершённый тест закрывает страницу сам** (410) — ручное снятие (`retired`) не нужно.
- **`/funnel` не принимает шаги страницы:** иначе просмотры посчитались бы дважды.

## Business hypothesis enabled by this phase

Тест с лендингом проходит от одобрения текста до публичной страницы двумя нажатиями, а воронка «внимание → клик» считается сама. Владелец переносит в `/funnel` только показы и траты с рекламной площадки.
