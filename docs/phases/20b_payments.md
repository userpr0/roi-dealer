## Objective

Платный предзаказ принимает деньги сам: кнопка страницы ведёт на ссылку оплаты Lemon Squeezy, провайдер присылает подписанный webhook, система записывает выручку, шаг воронки `payment` и возвраты. Тестовый платёж проверяет весь путь до публикации — без него Release Gate платный предзаказ не выпускает.

## Scope

### 1. Ссылка на оплату — сущность `Checkout` (19-я, миграция `0018`)

- **Поля:** тест, гипотеза, возможность, провайдер `lemonsqueezy`, ссылка, статус, время проверки тестовым платежом.
- **Ссылка:** только https на поддомене `lemonsqueezy.com`, путь `/buy/<id>` или `/checkout/buy/<id>`.
- **Задаёт и меняет только владелец** (`createCheckout`, `changeCheckoutUrl`); база — только от `owner` (CHECK). Одна активная ссылка на тест.
- **Проверена** (`markCheckoutTested`) — когда пришёл подписанный заказ этого теста в Test mode. Замена ссылки (тестовая → боевая) проверку сохраняет.

### 2. Пульт

- **`/checkout <№ теста> <ссылка>`** — только для платного предзаказа, не для завершённых тестов; «было → станет», подтверждение, одна команда владельца.
- **Карточка теста:** «💳 Оплата: ссылки нет — /checkout N …» / «ждёт тестовую покупку» / «проверена ✅».
- **Release Gate:** пункт «Оплата проверена тестовым платежом» — по `testedAt`.
- **Уведомления** — один раз на событие: тестовый платёж дошёл; оплата $X; возврат $X (записан или «внесите сами»).

### 3. Страница теста

- **Кнопка предзаказа** (`/l/<slug>/go`) — клик в воронку и `303` на ссылку владельца с `checkout[custom][experiment_id]` и `checkout[custom][utm_source]`. Без ссылки — прежний путь (форма или «спасибо»).

### 4. Webhook `POST /webhooks/lemonsqueezy` (`apps/api`, `@roi-dealer/payments`)

- **Подпись:** `X-Signature` — HMAC-SHA256 сырого тела с `LEMONSQUEEZY_WEBHOOK_SECRET`, сравнение в постоянное время; иначе `401`. Тело до 64 КБ, без секрета маршрута нет.
- **Читается только:** событие, номер и суммы заказа (`total_usd`, `tax_usd`, `refunded_amount_usd`), статус, режим теста, `custom_data`. Имя и почта покупателя не читаются, не хранятся, не логируются.
- **Пишет интеграция «Платежи Lemon Squeezy»** (`integration:lemonsqueezy`): доступ запрашивает `api`, одобряет владелец. Стоп-кран или нет доступа — `503` (провайдер повторит).
- **Что записывается** (одна транзакция, журнал `payment_events`, каждое событие один раз):
  - `order_created`, Test mode → `test_order`, ссылка теста проверена;
  - `order_created`, `paid` → `RevenueEntry` на сумму без налога: `preorder` для предзаказа, иначе `payment`; 1 клиент; привязка к тесту (если ссылка была с номером теста); шаг воронки `payment`, пока тест идёт;
  - `order_refunded` → прирост возврата (без налога, пропорционально заказу) — расход `refund` теста через `recordRefund`; если тест не запущен или возврат больше полученного — событие в журнале и уведомление «внесите сами».
- **Права:** у интеграций — `revenue.record` и `payment.record`; база пускает выручку от интеграции только от `integration:lemonsqueezy`.
- **Проверка трат:** возвраты провайдера не считаются автоматическими тратами (спенд-гард, PHASE 16).

## Out of scope

- Paddle — отдельным адаптером, если владелец выберет (ADR-0009, п. 6).
- Подписки, лицензии, налоговые отчёты — когда появится продукт (PHASE 22).
- Комиссия провайдера в экономике — видна в кабинете провайдера.

## Acceptance criteria

1. Ссылку задаёт только владелец, только для платного предзаказа; кнопка страницы ведёт на неё с номером теста.
2. Webhook без верной подписи ничего не пишет; с ней — тестовый платёж проверяет ссылку, оплата — выручка и шаг воронки, возврат — расход `refund`; повторная доставка ничего не повторяет.
3. Стоп-кран и доступ интеграции работают; данные покупателя не хранятся и не логируются.
4. Release Gate платный предзаказ без тестового платежа не выпускает.
5. typecheck, lint, format, тесты, build, образы — зелёные.

## Действия владельца

1. Аккаунт [Lemon Squeezy](https://www.lemonsqueezy.com/): магазин, условия и выплаты в вашу страну — при регистрации.
2. Для теста — товар с ценой из гипотезы и ссылка на оплату (сначала в Test mode).
3. **Settings → Webhooks → +:** адрес `<адрес api>/webhooks/lemonsqueezy`, события `order_created` и `order_refunded`, свой секрет (16+ символов).
4. Railway → `api` → Variables: `LEMONSQUEEZY_WEBHOOK_SECRET` = этот секрет. В чат не присылать.
5. `/decisions` → «Доступ: Платежи Lemon Squeezy» → ✅.
6. `/checkout <№> <ссылка Test mode>` → тестовая покупка → «✅ Тестовый платёж дошёл» → `/checkout <№> <боевая ссылка>`.
