# 36 — Свои объекты: недвижимость владельца в Украине

> **Статус:** спецификация. Направление одобрено D-040; архитектура — [ADR-0016](../ADR/0016-library-and-own-assets.md), часть 2, принята 2026-11-16 (D-041); дополнения D-042 (видение до 2035). План принят (D-043), фаза идёт. Пилот — раздел 4 [`PROJECT_BRIEF.md`](../PROJECT_BRIEF.md).
>
> **Ход:** шаги 1–2 готовы — объект и `/property`, библиотека, `/properties` с цифрами; фото через бота (кнопка «📷 Фото», размер Telegram до 1280 px, до 15 × 400 КБ); страница `/o/<slug>` на украинском с микроразметкой; заявка с телефоном; уведомление владельцу без телефона, «показать контакт», звонок/показ/сделка кнопками; удаление телефонов при закрытии, по `/forget` и через 180 дней (миграции `0029`, `0030`). Остался шаг 3 — пакет текстов (AI-задача `write-property-pack`); первый пакет Claude готовит вручную.

## Шаги

1. **Миграция `0029_properties`:**
   - сущность `properties`;
   - фото — таблица `property_photos`;
   - журнал воронки — таблица `property_funnel` (append-only);
   - контакты — таблица `property_contacts`: без событий, удаляются по-настоящему.
2. **Ввод объекта:** `/property` — вставленная анкета → разбор → карточка → подтверждение; фото — ответом на карточку.
3. **AI-задача `write-property-pack`:**
   - пакет текстов на украинском;
   - проверка кодом `checkPropertyPack`;
   - эталонный набор ≥ 20 случаев.
4. **Страница объекта** `/o/<slug>` на украинском:
   - фото отдаёт `apps/api`;
   - форма с телефоном;
   - политика конфиденциальности на украинском;
   - машиночитаемые данные объекта — разметка schema.org атрибутами microdata, без тега `script`: вид, сделка, площадь, цена, населённый пункт и улица без номера дома. Сегодня — для поисковиков, завтра — для AI-ассистентов покупателей (D-042).
5. **Метки каналов и счётчики:**
   - `view` и `lead` пишет сайт;
   - «📞 дзвінок», «👀 показ», «🤝 угода» — кнопками владельца;
   - метка материала `m=` рядом с меткой канала: короткий код ролика, поста или объявления из пакета объекта. Каждая заявка, звонок, показ и сделка связаны с объектом, каналом и материалом — так копится главное знание: какой материал продаёт (D-042). Адресов и данных людей в метках нет.
6. **Пульт:**
   - `/properties` — объекты с цифрами по каналам;
   - «показать контакт»;
   - смена статуса — с подтверждением.
7. **Удаление контактов:**
   - при `closed` и `withdrawn`;
   - по `/forget`;
   - через 180 дней.

## Тесты

- **unit:**
  - разбор анкеты;
  - `checkPropertyPack`: числа, пометка «оцінка», ссылки, запрещённые слова;
  - рендер страницы: экранирование, нет скриптов;
  - разметка schema.org на странице (без тега `script`);
  - метка материала: только коды из пакета объекта.
- **integration:**
  - заявка: согласие, ловушка, лимит, стоп-кран, одна транзакция со счётчиком;
  - 410 после закрытия;
  - удаление контактов;
  - кнопки владельца идемпотентны;
  - заявка, звонок, показ и сделка связаны с каналом и материалом.
