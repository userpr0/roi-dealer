# 36 — Свои объекты: недвижимость владельца в Украине

> **Статус:** спецификация. Направление одобрено D-040; архитектура — [ADR-0016](../ADR/0016-library-and-own-assets.md), часть 2, ждёт «одобряю ADR-0016». Пилот — [`PLAN.md`](../PLAN.md), раздел 4.

## Шаги

1. **Миграция `0029_properties`:**
   - сущность `properties`;
   - фото — таблица `property_photos`;
   - журнал воронки — таблица `property_funnel` (append-only);
   - контакты — таблица `property_contacts`: без событий, удаляются по-настоящему.
2. **Ввод объекта:** `/property` — вставленная анкета → разбор → карточка → подтверждение; фото — ответом на карточку.
3. **AI-задача `write-property-pack`:**
   - пакет текстов на украинском;
   - проверка кодом `checkPropertyPack`;
   - эталонный набор ≥ 20 случаев.
4. **Страница объекта** `/o/<slug>` на украинском:
   - фото отдаёт `apps/api`;
   - форма с телефоном;
   - политика конфиденциальности на украинском.
5. **Метки каналов и счётчики:**
   - `view` и `lead` пишет сайт;
   - «📞 дзвінок», «👀 показ», «🤝 угода» — кнопками владельца.
6. **Пульт:**
   - `/properties` — объекты с цифрами по каналам;
   - «показать контакт»;
   - смена статуса — с подтверждением.
7. **Удаление контактов:**
   - при `closed` и `withdrawn`;
   - по `/forget`;
   - через 180 дней.

## Тесты

- **unit:**
  - разбор анкеты;
  - `checkPropertyPack`: числа, пометка «оцінка», ссылки, запрещённые слова;
  - рендер страницы: экранирование, нет скриптов.
- **integration:**
  - заявка: согласие, ловушка, лимит, стоп-кран, одна транзакция со счётчиком;
  - 410 после закрытия;
  - удаление контактов;
  - кнопки владельца идемпотентны.
