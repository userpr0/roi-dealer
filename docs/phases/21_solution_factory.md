# PHASE 21 — Solution Factory (минимум): Release Gate и публикация лендинга

> **Основание:**
>
> - D-022 (Уровень 3, порядок 19a → 21 → 20 → 20b);
> - playbook §7.1 Step E–G (внутренняя проверка, Early User Crash Test, публичный тест с полной воронкой), §7.2 (Public Validation Release Gate);
> - конституция §2.3 (решает владелец), §2.13 (числа — код), §2.15 (Feature Kill Gate), §2.21 (разрешённый доступ);
> - PHASE 15 (единая воронка, ADR-0007: события своих страниц — источник `tracker`), PHASE 19a (лендинг, шаблон, предпросмотр).
>
> Спецификацию составил Claude (D-022). **Отчёт:** [21_solution_factory.report.md](21_solution_factory.report.md).

## Objective

Одобренный владельцем лендинг проходит Release Gate §7.2 и публикуется на `api` по адресу `/l/<slug>`. Пока тест идёт, страница сама считает шаги воронки «внимание» (просмотр) и «клики CTA». Тест с лендингом в системе не запускается, пока лендинг не выпущен.

## Business purpose

- **Тест без внешнего конструктора и счётчиков:** страницу публикует система; цифры просмотров и нажатий приходят в воронку сами, владелец вносит в `/funnel` только показы и траты с рекламной площадки.
- **Нет трафика без проверки** (§7.2): деньги на рекламу не уходят на страницу, которую никто не проверил.

## Scope

### 1. Release Gate (`releaseGate`, домен)

Проверки кодом — по фактам из базы, без AI:

| Пункт §7.2                                                 | Как проверяется                                                                                            |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Основной путь пользователя, ошибки и восстановление        | Лендинг одобрен владельцем; путь страница → кнопка → следующий шаг собирает код; 404 / 410 — свои страницы |
| Analytics / telemetry                                      | Интеграция «Сайт тестов» (счётчик) активна                                                                 |
| Секретов нет в клиенте, авторизация                        | Публичная страница собрана без скриптов и внешних адресов; она ничего не меняет                            |
| AI / API cost caps                                         | Запуск теста одобрен в `/decisions` (бюджет и stop-loss), AI — лимиты D-007 в коде                         |
| Метрика успеха и stop-loss до запуска                      | Метрика — шаг воронки, stop-loss задан                                                                     |
| Value proposition — результат                              | Чек-лист честной проверки подтверждён (PHASE 15)                                                           |
| Payment flow протестирован (если входит в гипотезу)        | Для платного предзаказа — проверенная оплата (PHASE 20b); до неё такой лендинг не выпускается              |
| Refund / cancel path                                       | Для предзаказа на странице — пометка «полный возврат» (код, 19a)                                           |
| Idempotency пользовательских действий, P0/P1, DB retrieval | Страница только читает; счётчик не считает повтор того же посетителя; тесты фазы                           |

Подтверждает владелец (Early User Crash Test и известные ошибки):

- `crash_test` — 2–3 человека открыли предпросмотр без подсказок и поняли, что предлагается и что будет после кнопки;
- `no_blockers` — страница проверена на телефоне: текст, цена и кнопка верны, блокирующих ошибок нет.

### 2. Выпуск (`releaseMediaAsset`, миграция `0016`)

- **Только владелец**, только одобренный лендинг, только при пройденном Gate и подтверждённых пунктах владельца.
- **`MediaAsset`:** `released` с временем выпуска и подтверждёнными пунктами (`releaseChecks`); в базе — CHECK.

### 3. Публичная страница (`apps/api`, `@roi-dealer/site`)

- **`GET /l/<slug>`** — страница по шаблону `renderLanding` (режим `public`), пока тест одобрен или идёт. Тест остановлен, завершён или отменён — честная страница «тест завершён» (410). Не выпущен — 404.
- **`GET /l/<slug>/go`** — нажатие кнопки → 303 на следующий шаг (`/l/<slug>/thanks` — «продукт в разработке, спасибо за интерес»; форма заявки — PHASE 20, оплата — PHASE 20b).
- **UTM-метки** из адреса переходят в ссылку кнопки и в события.
- **Безопасность:** те же заголовки, что у предпросмотра; без cookies; `noindex`.

### 4. Счётчик воронки (`createSiteTracker`)

- **Что считает:** `attention` — просмотр страницы, `cta_click` — нажатие кнопки; источник `tracker`, канал гипотезы, UTM. Только пока тест **идёт**: просмотры crash test до запуска не попадают в воронку.
- **От чьего имени:** интеграция «Сайт тестов» (`integration:site`). Доступ запрашивает `api` при старте; владелец одобряет в `/decisions`. Новое право `funnel.track` — только события своих страниц.
- **Стоп-кран** останавливает запись событий; страница продолжает открываться.
- **Защита от накрутки:**
  - один и тот же посетитель (хеш адреса и браузера в памяти, с солью процесса) считается один раз за 30 минут на шаг;
  - роботы и превью ссылок (Telegram, Slack и т. п.), предзагрузка, `HEAD` — не считаются;
  - не больше 600 событий в минуту на процесс.
- **Приватность:** IP, браузер и cookies не хранятся и не логируются.

### 5. Пульт

- **Карточка лендинга:** у одобренного — кнопка **🚦 Release Gate** → список пунктов ✅ / ❌ с тем, что исправить. Всё ✅ → **🚀 Выпустить** → вопрос с пунктами владельца → **Да** → одна команда владельца.
- **После выпуска** — ссылка на страницу и пример ссылки с UTM для рекламы.
- **`/experiments`:** строка «🎨 Лендинг: 🌐 опубликован»; **▶️ Тест запущен** у теста с лендингом в системе — только после выпуска.
- **`/funnel`:** у теста с выпущенным лендингом «внимание» и «клики CTA» не принимаются — их считает страница.

### 6. Журнал запросов `api`

Адрес предпросмотра в логах — `/p/:token`: закрытая ссылка не попадает в логи.

## Out of scope

- **Форма заявки, политика конфиденциальности, данные клиентов** — PHASE 20.
- **Оплата и возвраты** — PHASE 20b.
- **Свой домен** — адрес сервиса `api` в Railway; свой домен — когда понадобится (§2.15).
- **Снятие страницы вручную (`retired`)** — завершённый тест закрывает страницу сам.
- **Сборка продуктов (Build / Buy / Improve, MSP)** — после первых результатов тестов (D-022).

## Acceptance criteria

1. Release Gate показывает пункты §7.2; выпуск — только владелец, при пройденном Gate и подтверждённых пунктах (домен и база).
2. `/l/<slug>` отдаёт страницу без скриптов; после теста — 410; невыпущенная — 404.
3. Просмотр и нажатие записываются в воронку от интеграции, только пока тест идёт, один раз на посетителя за 30 минут; роботы и предзагрузка не считаются; стоп-кран останавливает запись.
4. Тест с лендингом в системе не запускается до выпуска; `/funnel` не принимает шаги, которые считает страница.
5. typecheck, lint, format, тесты, build, образы — зелёные.

## Действия владельца после вливания

- `/decisions` → «Доступ: Сайт тестов» → ✅ (карточка придёт, когда запущен сервис `api`).
