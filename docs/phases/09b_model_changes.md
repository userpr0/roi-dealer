# 09b — «Смена моделей по тестам»: паспорт, претенденты, допуск владельцем

> **Статус:** реализована ([отчёт](09b_model_changes.report.md)).
> **Основание:** [ADR-0014](../ADR/0014-model-changes-by-tests.md); одобрена D-034.
> **Принципы:** место модели решают наши эталоны (§2.13); новая модель в работе — только после решения владельца.

## Что сделано

- **Паспорт модели** в реестре (`ModelSpec.passport`):
  - что умеет: текст, картинки, видео, звук на входе;
  - условия данных и права на результат. У шести действующих моделей стоит «не проверено» — их проверит `model-scout` по официальным страницам и пришлёт PR;
  - дата снятия, источник, дата проверки.
- **Допуск:**
  - действующие модели — `standing` (ADR-0006, D-021);
  - новая модель входит как `candidate`: проходит эталоны, но реальных вызовов не получает;
  - владелец допускает или отклоняет кандидата в `/models` (подтверждение, журнал `model_admissions`, миграция `0024`);
  - отклонённая модель не работает и не проходит эталоны.
- **Сравнение кодом:** по каждой задаче претендент против первой допущенной модели своего уровня (bulk — по цене, strong — по точности). «Лучше» — та же точность дешевле или выше точность. Рекомендация «допустить»: всё прогнано, ничего не хуже, хоть что-то лучше.
- **Новые модели провайдеров:** ежедневная сверка списков записывает id в `provider_models`. Первый список — база, всё, что появилось позже, — новое. `/models` показывает новые id, дайджест — строку «🆕 Новых моделей у провайдеров за сутки».
- **Снятие с поддержки:** `/models` предупреждает за 30 дней по `retiresOn`.
- **Возможности, которых ждут процессы** (`CAPABILITY_WISHES`):
  - проверка лендинга по скриншоту;
  - разбор ролика как параметров;
  - озвучка.

  `/models` показывает, какие модели это уже умеют. Новый процесс — только отдельной фазой.

- **Ловушки в эталонах:** `EvalCase.trap` и `AiTask.externalText`. Модель проходит эталон, только если каждую ловушку решает правильно сама по себе (`withTraps`, метрика `traps`). У `extract-signal` — 2 ловушки.

## Не входит (Feature Kill Gate)

- Ловушки для остальных задач с чужим текстом (`match-pain`, `frame-opportunity`, `market-context`, `judge-opportunity`, `redact-names`) — следующим шагом, с новой версией каждой задачи. Без смены версии эталоны не перепрогоняются, и задачи не встают.
- Навык `model-scout` — отдельным файлом в `.claude/skills/` при первой новой модели.
