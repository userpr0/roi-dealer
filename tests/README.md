# tests

Все тесты запускаются из корня repository (Vitest, `vitest.config.ts`).

| Каталог        | Команда                 | Что тестируется                                                              |
| -------------- | ----------------------- | ---------------------------------------------------------------------------- |
| `unit/`        | `pnpm test:unit`        | Чистая логика in-process: без сокетов, процессов и внешних сервисов          |
| `integration/` | `pnpm test:integration` | Реальные HTTP-сокеты и OS-процессы (сигналы, exit codes); далее — PostgreSQL |
| `e2e/`         | —                       | Сквозные сценарии (появятся вместе с user journeys)                          |
| `fixtures/`    | —                       | Статические тестовые данные                                                  |
| `support/`     | —                       | Общие хелперы (capturing logger, запуск процессов)                           |

`pnpm test` запускает unit и integration.

Тесты импортируют workspace-пакеты по имени (`@roi-dealer/...`); благодаря export condition `@roi-dealer/source` используются исходники, а не `dist/`, так что предварительная сборка не нужна.

Правила:

- failing test не отключается и не помечается `skip` ради зелёного CI;
- тесты не используют реальные секреты и внешние платные API;
- дочерние процессы в integration-тестах получают минимальное окружение (только `PATH` и явно заданные переменные).
